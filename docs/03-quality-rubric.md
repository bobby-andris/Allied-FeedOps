# Allied FeedOps: Quality Scoring Rubric

## Overview

Every piece of content generated by FeedOps is scored against six dimensions derived from the optimization research. This ensures consistent quality and measurable improvement.

---

## Scoring Thresholds

| Score | Status | Action |
|-------|--------|--------|
| **≥80%** | APPROVED | Ready for publication |
| **70-79%** | REVISE | Minor improvements needed |
| **<70%** | REJECT | Major revision required |

**Critical Override**: If Factual Accuracy < 8/10, content is automatically REJECTED regardless of composite score.

---

## Dimension 1: Specificity Score (0-10)

### What We're Measuring
The ratio of specific, verifiable claims to vague, generic claims.

### Why It Matters
- Specific claims activate dual cognitive processing (verbal + visual)
- Verifiable claims build trust
- Generic claims signal lack of product knowledge
- Research shows "corrosion-resistant solid brass" outperforms "premium quality"

### Scoring Method

**Step 1**: Count Specific Claims
```
Specific claims include:
- Exact dimensions: "24-inch", "2.5-inch projection"
- Materials: "solid brass", "stainless steel"
- Capacities: "500 lb capacity", "holds 4 bath towels"
- Certifications: "ADA compliant", "UL listed"
- Measurable features: "concealed mounting", "tilt-adjustable 180°"
- Concrete outcomes: "corrosion-proof", "rust-resistant"
```

**Step 2**: Count Vague Claims
```
Vague claims include:
- Quality words: "high-quality", "premium", "best"
- Strength words: "durable", "sturdy", "strong" (without specs)
- Aesthetic words: "beautiful", "elegant" (without specifics)
- Process words: "easy to install" (without details)
- Superlatives: "amazing", "incredible", "revolutionary"
```

**Step 3**: Calculate Score
```
Score = (Specific Claims / Total Claims) × 10
```

### Examples

**10/10**: "Crafted from solid brass with a 500-pound weight capacity, featuring knurled grip and concealed mounting hardware."
- Specific: solid brass, 500-pound, knurled grip, concealed mounting (4)
- Vague: 0
- Score: 4/4 × 10 = 10

**5/10**: "Made from premium materials, this sturdy grab bar is easy to install."
- Specific: 0
- Vague: premium, sturdy, easy (3)
- Score: 0/3 × 10 = 0 (round to minimum 1 if content exists)

## Dimension 2: Benefit Coverage (0-10)

### What We're Measuring
Whether the first 150 characters contain a clear benefit statement.

### Why It Matters
- First 150 characters show in previews/snippets
- Benefits trigger emotional engagement (System 1)
- Benefits answer "why should I buy this?"
- Research: 95% of decisions start with emotional response

### Scoring Scale

| Score | Criteria | Example |
|-------|----------|---------|
| **10** | Benefit + key spec in opening sentence | "Protect your loved ones with this ADA-compliant grab bar supporting up to 500 pounds." |
| **8** | Clear benefit in first 150 chars | "Keep your bathroom clutter-free with this elegant 24-inch towel bar." |
| **6** | Benefit present but not leading | "This 24-inch towel bar, perfect for luxury bathrooms, is made from solid brass." |
| **4** | Feature-first, benefit implied | "This 18-inch grab bar is made of solid brass and comes in satin nickel." |
| **2** | Features only, no benefit stated | "Solid brass grab bar measuring 18 inches with satin nickel finish." |
| **0** | Generic/empty opening | "Great product for your bathroom." |

### The Benefit Test
Ask: "Can a reader immediately understand WHY they should buy after reading the first sentence?"
- Yes → Score 8-10
- Partially → Score 4-7
- No → Score 0-3

## Dimension 3: Keyword Inclusion (0-10)

### What We're Measuring
Presence and placement of target keywords in titles and descriptions.

### Why It Matters
- Google weighs words at beginning of title more heavily
- First 70 characters determine what users see
- Keywords in description capture long-tail queries
- Research: Front-loaded keywords can yield +88% CTR

### Scoring Checklist

**Title Points (Max 6)**:
| Element | Points | Check |
|---------|--------|-------|
| Brand in first 70 chars | +2 | [ ] |
| Product type in first 70 chars | +2 | [ ] |
| Primary dimension in title | +1 | [ ] |
| Functional modifier present | +1 | [ ] |

**Description Points (Max 4)**:
| Element | Points | Check |
|---------|--------|-------|
| Primary keyword in first sentence | +2 | [ ] |
| Related terms/synonyms included | +1 | [ ] |
| Use-case language present | +1 | [ ] |

### Examples

**10/10 Title**: "Allied Brass 24-Inch Towel Bar | Solid Brass | Polished Chrome | Wall Mount"
- Brand (Allied Brass): ✓ +2
- Product type (Towel Bar): ✓ +2
- Dimension (24-Inch): ✓ +1
- Functional (Wall Mount): ✓ +1
- Total: 6/6

**4/10 Title**: "Polished Chrome Hardware for Bathroom Use"
- Brand: ✗
- Product type: ✗
- Dimension: ✗
- Functional: ✗
- Total: 0/6

## Dimension 4: Format Adherence (0-10)

### What We're Measuring
Compliance with character limits, structure requirements, and formatting rules.

### Why It Matters
- Character limits are platform requirements
- Structure affects readability and scanning
- Format violations can cause disapprovals
- Research: 79% of users scan rather than read

### Scoring Checklist

**Title Requirements (Max 5)**:
| Requirement | Points | Check |
|-------------|--------|-------|
| ≤150 characters | +2 | [ ] |
| ≥50 characters (not too short) | +1 | [ ] |
| Proper separators (|, –, ,) | +1 | [ ] |
| No ALL CAPS words | +0.5 | [ ] |
| No promotional text | +0.5 | [ ] |

**Description Requirements (Max 5)**:
| Requirement | Points | Check |
|-------------|--------|-------|
| ≥500 characters | +2 | [ ] |
| Bullet points for highlights | +1 | [ ] |
| Structured sections visible | +1 | [ ] |
| First 150 chars standalone | +1 | [ ] |

### Automatic Deductions
- Title exceeds 150 chars: -5 (REJECT)
- ALL CAPS words present: -2
- Promotional text ("FREE!", "SALE!"): -3
- No bullet points in 500+ char description: -1

## Dimension 5: Brand Voice (0-10)

### What We're Measuring
Alignment with premium brand tone and vocabulary guidelines.

### Why It Matters
- Consistent voice builds brand recognition
- Premium language justifies premium pricing
- Wrong tone can undermine trust
- Research: Premium brands avoid superlatives as "vocabulary of the high street"

### Premium Voice Indicators (+2 each, max 10)

| Indicator | Example |
|-----------|---------|
| Uses "crafted", "engineered", "precision" | "Crafted from solid brass..." |
| References specific materials properly | "...solid brass that resists corrosion..." |
| Understated, confident tone | "Enduring elegance" not "AMAZING quality!" |
| Includes specific numbers/measurements | "500-pound capacity" not "very strong" |
| Mentions warranty/guarantee | "Backed by lifetime warranty..." |

### Deductions

| Issue | Deduction |
|-------|-----------|
| Superlatives (best, amazing, incredible) | -3 |
| ALL CAPS words | -2 |
| Exclamation points in description | -1 |
| Generic marketing fluff | -2 |
| Budget language (cheap, affordable, bargain) | -3 |

### Voice Calibration

**Premium (Target)**:
"Crafted from solid brass that will never corrode, peel, or tarnish, this towel bar brings enduring elegance to your bathroom."

**Generic (Avoid)**:
"This amazing towel bar is made from high-quality materials and looks beautiful in any bathroom!"

**Budget (Never)**:
"Great value! This cheap but sturdy towel bar is an affordable option for budget-conscious buyers!"

## Dimension 6: Factual Accuracy (0-10)

### What We're Measuring
Whether every claim in the content can be traced to source product data.

### Why It Matters
- Invented claims are deceptive to buyers
- Inaccurate specs lead to returns
- Platform policies prohibit misrepresentation
- Core principle: NO HALLUCINATION

### Scoring Scale

| Score | Criteria |
|-------|----------|
| **10** | All claims verifiable against source data |
| **8** | Minor unverified claim (subjective quality statement) |
| **5** | Unverified specification present |
| **0** | Invented specification detected |

### Verification Process

```
FOR each claim in content:
  1. Identify claim type (dimension, material, capacity, feature, certification)
  2. Locate corresponding field in product data
  3. Compare exact values
  4. Record match/mismatch
```

### Verification Table Example

| Claim | Source Field | Source Value | Match |
|-------|-------------|--------------|-------|
| "24-inch" | dimensions.length | "24 inches" | ✓ |
| "solid brass" | material | "Solid Brass" | ✓ |
| "500 lb capacity" | weight_capacity | "500 lbs" | ✓ |
| "lifetime warranty" | warranty | "Lifetime construction" | ✓ |
| "easy installation" | - | Not specified | ⚠️ (unverifiable) |

### Critical Rule

**Score below 8 triggers automatic REJECT.**

If ANY invented specification is detected (score = 0), the content MUST be rejected and regenerated with correct data.

## Composite Score Calculation

### Formula

```
Composite = (Specificity + Benefits + Keywords + Format + Voice + Accuracy) / 60 × 100
```

### Worked Example

| Dimension | Score |
|-----------|-------|
| Specificity | 9/10 |
| Benefit Coverage | 10/10 |
| Keyword Inclusion | 8/10 |
| Format Adherence | 10/10 |
| Brand Voice | 9/10 |
| Factual Accuracy | 10/10 |
| **Total** | 56/60 |
| **Composite** | **93%** |

### Decision Logic

```python
def evaluate_content(scores):
    # Check critical threshold
    if scores['accuracy'] < 8:
        return 'REJECT', 'Factual accuracy below threshold'
    
    # Calculate composite
    composite = sum(scores.values()) / 60 * 100
    
    # Apply thresholds
    if composite >= 80:
        return 'APPROVED', f'{composite:.0f}% - Ready for publication'
    elif composite >= 70:
        return 'REVISE', f'{composite:.0f}% - Minor improvements needed'
    else:
        return 'REJECT', f'{composite:.0f}% - Major revision required'
```
