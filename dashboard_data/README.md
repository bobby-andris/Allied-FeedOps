# Streamlit Cloud Demo Data

This folder contains a small, repo-friendly dataset for the Streamlit review dashboard.

Contents:
- `lifestyle-eval/`: Patch JSONs for 19 SKUs with verified lifestyle images
- `catalog.csv`: Minimal catalog subset used for category/collection + original content

Use `streamlit_app.py` as the Streamlit Cloud entrypoint to run the dashboard
against this dataset without any extra configuration.
