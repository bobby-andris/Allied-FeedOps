    **Bug 1 — Search terms variant attribution:**
    Trace the exact line in `fetch_search_terms()` where variant attribution occurs. The bug is:
    - Line ~597-603: after fetching all items for a campaign, it assigns `gmc_offer_id = item_ids[0]` — the FIRST item in the campaign list regardless of which variant actually triggered the search term.
    - Because `item_ids` from `_fetch_campaign_products()` is sorted by impressions DESC (line ~488), it assigns the highest-impression variant of the campaign to ALL search terms in that campaign.
    - This means all search terms for a campaign get attributed to the same variant, not to the variant that actually triggered them. The per-campaign join fails to achieve variant-level attribution.
    - The `master_sku` on the saved row IS correct (it's derived from the gmc_offer_id lookup), but all variants of a SKU in the same campaign share the same gmc_offer_id in the saved rows.

    **Bug 2 — Performance metrics via shopping_performance_view:**
    Trace whether `collect_performance_batch()` correctly uses offer IDs from `variant_index`.
    - `variant_index` stores offer IDs as lowercase (`shopify_us_...`) per SCHEMA.md
    - `shopping_performance_view` returns `segments.product_item_id` — check if this is uppercase or lowercase
    - `fetch_batch_product_performance()` uses the offer IDs from `variant_index` directly as the IN clause
    - Confirm: does the API return data when queried with lowercase offer IDs? The GAQL query at line ~343 uses the IDs as-is from the input list.
    - Check if there is a case mismatch: Google Ads stores offer IDs as `shopify_US_` (uppercase) but variant_index has `shopify_us_` (lowercase). If the IN clause uses lowercase, the shopping_performance_view may return zero rows because no match.

    **Query 2: How many distinct gmc_offer_ids per master_sku in search_queries?**
    ```sql
    SELECT
        sq.master_sku,
        COUNT(DISTINCT sq.gmc_offer_id) AS distinct_offer_ids,
        COUNT(DISTINCT vi.finish_code) AS expected_variants,
        COUNT(DISTINCT sq.query_text) AS unique_queries
    FROM search_queries sq
    LEFT JOIN variant_index vi ON vi.master_sku = sq.master_sku
    WHERE sq.master_sku IN (
        SELECT DISTINCT master_sku FROM publish_events
        WHERE platform = 'google'
        ORDER BY published_at DESC
        LIMIT 5
    )
    GROUP BY sq.master_sku
    ORDER BY sq.master_sku;
    ```
