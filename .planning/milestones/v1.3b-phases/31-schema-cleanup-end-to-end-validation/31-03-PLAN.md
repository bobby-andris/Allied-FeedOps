  <name>Task 2: E2E validation walkthrough with real production SKU</name>
  <files>.planning/phases/31-schema-cleanup-end-to-end-validation/31-e2e-validation-report.md</files>
  <action>
    Perform a manual E2E validation walkthrough and document findings as a validation report.

    1. **Find the best SKU for validation.** Query production for a SKU with the richest data coverage:
    ```sql
    SELECT gc.master_sku,
           COUNT(DISTINCT pe.id) as publish_events,
           COUNT(DISTINCT pb.id) as baselines,
           COUNT(DISTINCT ps.id) as snapshots,
           COUNT(DISTINCT sq.id) as search_queries
    FROM generated_content gc
    LEFT JOIN publish_events pe ON pe.master_sku = gc.master_sku
    LEFT JOIN performance_baselines pb ON pb.master_sku = gc.master_sku
    LEFT JOIN performance_snapshots ps ON ps.master_sku = gc.master_sku
    LEFT JOIN search_queries sq ON sq.custom_label_0 = gc.master_sku
    GROUP BY gc.master_sku
    HAVING COUNT(DISTINCT pe.id) > 0
    ORDER BY publish_events DESC, snapshots DESC, baselines DESC
    LIMIT 5;
    ```
    Pick the SKU with the most coverage across all tables.

    2. **Trace the full loop** for the chosen SKU:

    a. **Generated content exists:**
    ```sql
    SELECT master_sku, platform, content_type, quality_score, created_at
    FROM generated_content WHERE master_sku = '{sku}';
    ```

    b. **Publish event exists (with prompt_hash):**
    ```sql
    SELECT id, master_sku, platform, prompt_hash, published_at
    FROM publish_events WHERE master_sku = '{sku}';
    ```

    c. **Performance baseline exists:**
    ```sql
    SELECT master_sku, platform, avg_impressions, avg_clicks, avg_ctr
    FROM performance_baselines WHERE master_sku = '{sku}';
    ```

    d. **Performance snapshot exists:**
    ```sql
    SELECT master_sku, platform, impressions, clicks, ctr, days_since_publish
    FROM performance_snapshots WHERE master_sku = '{sku}';
    ```

    e. **Content-performance feedback view works:**
    ```sql
    SELECT * FROM content_performance_summary WHERE master_sku = '{sku}';
    ```

    f. **Funnel snapshot data exists:**
    ```sql
    SELECT snapshot_date, tier, search_term_count, total_impressions
    FROM funnel_snapshots_daily
    ORDER BY snapshot_date DESC LIMIT 5;
    ```
