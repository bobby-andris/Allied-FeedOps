  <action>
Create a Python script `scripts/phase3_performance_test.py` that measures API query performance (SAMP-05):

**Setup:**
1. Load Google Ads client from env vars (same pattern as Phase 1 scripts - `use_proto_plus: True`, customer_id `6253381786`)
2. Load sample SKUs from `.planning/phases/03-sample-testing-analysis/sample-skus.json`
3. Collect all `gmc_offer_id` values from sample SKUs

**Performance Measurement (SAMP-05):**
1. Test these batch sizes: 1, 3, 5, 10 (using offer IDs from sample SKUs)
2. For each batch size, construct a `shopping_performance_view` query with IN clause:
   ```sql
   SELECT segments.product_item_id, segments.date,
          metrics.impressions, metrics.clicks, metrics.cost_micros,
          metrics.conversions, metrics.conversions_value
   FROM shopping_performance_view
   WHERE segments.product_item_id IN ({offer_ids})
     AND segments.date DURING LAST_30_DAYS
   ```
3. Run each query 5 times using `time.perf_counter()` (NOT `time.time()`)
4. Use `search_stream` (not `search`) for consistency with production code
5. Consume ALL results from the stream (iterate all batches) before stopping timer
6. Calculate percentiles using numpy: p50, p95, p99, min, max, mean
7. Also count total rows returned per query

Save to `query-performance.json`:
```json
{
  "metadata": {"date": "2026-02-12", "iterations_per_batch": 5, "customer_id": "6253381786"},
  "results": {
    "1": {"p50_ms": N, "p95_ms": N, "p99_ms": N, "min_ms": N, "max_ms": N, "mean_ms": N, "avg_rows": N},
    "3": {"p50_ms": N, ...},
    "5": {"p50_ms": N, ...},
    "10": {"p50_ms": N, ...}
  },
  "recommendations": {
    "optimal_batch_size": N,
    "estimated_total_time_minutes": N,
    "reasoning": "..."
  }
}
```

Calculate `estimated_total_time_minutes` based on: 2,784 SKUs / optimal_batch_size * p95 response time + rate limit delays.

Print performance table to stdout showing batch size, p50, p95, p99, avg rows.
