Create a Python script `scripts/phase3_keyword_gap.py` that performs SAMP-03 (Keyword Planner ideas) and SAMP-04 (opportunity gap calculation):

**Inputs:** Read from Plan 03-01 outputs:
- `.planning/phases/03-sample-testing-analysis/sample-skus.json` (SKU list with titles)
- `.planning/phases/03-sample-testing-analysis/search-terms-by-sku.json` (current search terms)

**Part 1 - Keyword Planner Ideas (SAMP-03):**
1. Load Google Ads client (same pattern as Phase 1 scripts - env vars, `use_proto_plus: True`, customer_id `6253381786`)
2. For each SKU in sample-skus.json, use the product title as a keyword seed
3. Call Keyword Planner `GenerateKeywordIdeas` service:
   - Use `KeywordSeed` with the product title
   - Language: `languageConstants/1000` (English)
   - Geo target: `geoTargetConstants/2840` (USA)
   - Collect up to 100 ideas per SKU
4. For each idea, capture: keyword text, avg_monthly_searches, competition (LOW/MEDIUM/HIGH), competition_index (0-100), low_top_of_page_bid_micros, high_top_of_page_bid_micros
5. Add 1-2 second delay between SKU requests (Keyword Planner has lower rate limits than other APIs)

Save to `keyword-ideas-by-sku.json`:
```json
{
  "metadata": {"date": "2026-02-12", "language": "English", "geo": "USA"},
  "skus": {
    "MASTER-SKU-1": {
      "seed_keyword": "Product Title Here",
      "idea_count": N,
      "ideas": [
        {
          "text": "keyword phrase",
          "avg_monthly_searches": N,
          "competition": "LOW|MEDIUM|HIGH",
          "competition_index": N,
          "low_cpc_micros": N,
          "high_cpc_micros": N
        }
      ]
    }
  }
}
```

**Part 2 - Opportunity Gap Analysis (SAMP-04):**
1. Load search terms from `search-terms-by-sku.json`
2. For each SKU, normalize all keywords to lowercase and strip whitespace
3. Filter KP ideas to high-volume terms only (avg_monthly_searches >= 100)
4. Calculate gap: KP ideas NOT present in current Google Ads search terms
5. Sort gap keywords by search volume descending

Save to `opportunity-gaps.json`:
```json
{
  "metadata": {"date": "2026-02-12", "min_monthly_searches": 100},
  "summary": {
    "total_skus": N,
    "avg_coverage_rate": 0.XX,
    "total_gap_volume": N,
    "total_gap_keywords": N
  },
  "skus": {
    "MASTER-SKU-1": {
      "current_search_terms": N,
      "kp_high_volume_ideas": N,
      "gap_count": N,
      "gap_volume": N,
      "coverage_rate": 0.XX,
      "top_gaps": [
        {"text": "keyword", "avg_monthly_searches": N, "competition": "...", "competition_index": N}
      ]
    }
  }
}
```

Print summary table to stdout showing: SKU, category, current terms, KP ideas, gap count, gap volume, coverage rate.

**Error handling:** If Keyword Planner fails for a specific SKU (rate limit, etc.), log the error and continue to next SKU. Don't fail the entire script.
