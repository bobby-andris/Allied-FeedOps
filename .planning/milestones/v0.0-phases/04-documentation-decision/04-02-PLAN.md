**Alternative Strategies section (DOC-05):**

Document workarounds for each discovered limitation, extracted from STATE.md decisions and SUMMARY files:

1. **search_term_view cannot filter by product** (Decision #1)
   - Limitation: API rejects product_item_id in search_term_view WHERE
   - Alternative: Campaign-join pattern (shopping_performance_view → search_term_view)
   - Status: RESOLVED - working pattern validated in Phase 3 (60K+ terms fetched)
   - Impact: Two-step query adds ~1s overhead, negligible at scale

2. **Auction Insights not available via API** (Decision #9)
   - Limitation: API returns access restriction error for auction_insight_* metrics
   - Alternative: Use own-account impression_share and click_share metrics (available in shopping_performance_view)
   - Status: PARTIAL - own metrics available but no competitor-specific data
   - Impact: Can track own competitive position, cannot compare to specific competitors

3. **Three metrics incompatible with shopping_performance_view** (Decisions #14-15)
   - average_cpm → Use average_cpc instead (available)
   - search_budget_lost_impression_share → Not available for Shopping (campaign management metric)
   - search_rank_lost_impression_share → Not available for Shopping (campaign management metric)
   - Status: RESOLVED - alternative metrics available, removed metrics are LOW value for content optimization

4. **Competitive metrics partial coverage (~33% of SKUs)** (Decision from 03-03)
   - Limitation: impression_share/click_share only populated when sufficient volume
   - Alternative: Focus competitive tracking on top-performing SKUs, use CTR trend for others
   - Status: ACCEPTABLE - 33% covers highest-value products (most impressions)

5. **LAST_N_DAYS syntax not supported** (Decision #12)
   - Limitation: API rejects date literals like LAST_90_DAYS
   - Alternative: Calculate explicit date ranges in Python code
   - Status: RESOLVED - trivial code change, all scripts already use explicit dates

6. **Asset performance_label not available in API v22** (from 02-04)
   - Limitation: Field unrecognized in current API version
   - Alternative: Use ad_strength metric from asset_group view instead
   - Status: RESOLVED - ad_strength provides similar signal
