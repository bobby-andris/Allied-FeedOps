## Decisions Made
- **Self-score: 3 criteria, not 10.** The 10-criterion rubric caused the model to optimize for scores rather than quality (Pitfall 5). Simplified to accuracy, specificity, engagement. Full rubric reserved for separate evaluation pass.
- **Gold examples: keep in user prompt for now.** System prompt placement is more cache-efficient, but gold examples are loaded dynamically from Supabase. A/B test in Plan 03 will determine the best placement.
- **Competitor materials: absolute prohibition.** All 4 sources that mentioned competitor materials (brand_voice, shopping_intelligence, storytelling_patterns, SYSTEM_PROMPT) resolved to a single P0 prohibition. No exceptions.
- **Description length: 700-900 chars.** Three sources agreed on this (SYSTEM_PROMPT, shopping_intelligence.yaml, google-shopping SKILL.md). The conflicting 600-800 in CANDIDATE_SCHEMA will be updated during implementation.
- **Feature flag approach for A/B testing.** prompt_version parameter in get_system_prompt() allows both old and new paths to coexist without code deletion.
