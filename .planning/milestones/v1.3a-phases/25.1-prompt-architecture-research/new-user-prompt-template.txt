User Prompt Template for GPT-5.2 Content Generation (v2.1 — Variant-Level Primary)
=====================================================================================

IMPORTANT: Google/Bing content is ALWAYS variant-level (a specific finish).
The VARIANT template below is the PRIMARY template for A/B testing and production.
The master-SKU template is used ONLY for Shopify (finish-agnostic) content.

Removed from v1 template:
- {segment_strategy_guidance} — absorbed into system prompt constraints
- Gold examples moved to system prompt (static, cacheable)

{finish_compelling_sentence}
