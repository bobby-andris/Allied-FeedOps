# Phase 25.1-03: A/B Test New Prompt + Bobby Gut-Check

## Status: COMPLETE (negative result — spawned Phase 25.2)

## What Was Done
1. Built `scripts/ab_prompt_test.py` validation harness
2. Tested 3 prompt variations on representative + unseen SKUs:
   - Current (baseline)
   - Minimal (stripped to 8.2K)
   - Optimized (18.3K distilled with CTCO architecture)
3. Bobby gut-check review completed

## Result
Variation C (Optimized) won on structure but FAILED on constraint adherence:
- Banned words leaked into output
- `{FINISH_SENTENCE}` pattern violations
- Keyword stuffing worse than baseline
- Generic openings instead of product-specific design stories
- Evidence "poison pills" echoed into customer-facing copy

Bobby's gut-check was negative, which directly spawned Phase 25.2 to address GPT-5.2 adherence at a deeper level.

## Key Learning
Prompt size is not the issue — prompt QUALITY is. The v2 stripped prompt removed essential domain knowledge. The solution was to distill knowledge into structured creative briefs, not strip it.
