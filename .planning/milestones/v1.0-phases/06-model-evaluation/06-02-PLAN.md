# Plan 06-02: Skill-Adapted Prompt + Evaluation Run

## Goal
Adapt the gmc-product-optimizer skill for pipeline use, create GOOGLE_BRIEF_V3, and run the 10 evaluation SKUs with Sonnet 4.6 + skill prompt to validate quality.

## Research
See: `.planning/phases/06-model-evaluation/06-02-RESEARCH.md`

## Tasks

### Task 1: Adapt skill and create GOOGLE_BRIEF_V3
**Files:** `src/feedops/pipeline/prompts.py`

1. Create `GOOGLE_BRIEF_V3` constant in prompts.py that merges:
   - Skill's description structure (8-step: benefit hook → {FINISH_SENTENCE} → design romance → material → features → cross-sell specifics → installation → warranty close)
   - Skill's title guidance adapted for pipeline (pipe separators, but `{FINISH_NAME}` first)
   - Skill's worked examples adapted with `{FINISH_NAME}` prefix and `{FINISH_SENTENCE}` uppercase
   - Skill's anti-patterns (no generic openers, no filler, name specific accessory types)
   - Pipeline's existing constraints (JSON output contract, platform rules, final quality gate)

2. Update `get_platform_system_prompt()` in `skill_loader.py` (or equivalent) to respect `FEEDOPS_GOOGLE_BRIEF_VERSION` env var:
   - `v2` (default): Use existing `GOOGLE_BRIEF`
   - `v3`: Use new `GOOGLE_BRIEF_V3`

3. Do NOT change Bing or Shopify briefs in this plan (Google-only for evaluation)

### Task 2: Run 10-SKU evaluation with skill prompt
**Files:** `docs/evaluation/skill_eval_results.md`

1. Set env: `FEEDOPS_PROVIDER=claude`, `FEEDOPS_GOOGLE_BRIEF_VERSION=v3`
2. Run evaluation script for Google platform only (the skill is Google-focused):
   ```bash
   PYTHONPATH=./src python scripts/run_model_evaluation.py \
     --skus "DM-1/3X" "433/18" "CM-P-700-24-GB" "2020T" "1032" "CC-64" "1041/24" "AP-94" "CVTS-25" "404-12BB" \
     --models claude-sonnet-4-6 \
     --passes 1 \
     --platforms google \
     --output-dir docs/evaluation
   ```
3. Present results for Bobby/Robert review — these are real content for real SKUs with no existing generated content, so approved outputs go directly to the review queue

### Task 3: Document results
**Files:** `docs/evaluation/skill_eval_results.md`

1. For each SKU, show: title, description, character count
2. Compare against existing Sonnet 4.6 results from Plan 06-01 (same SKUs, different prompt)
3. Note any {FINISH_SENTENCE}/{FINISH_NAME} compliance issues
4. Bobby/Robert pass/fail assessment
