Create `src/feedops/jobs/quality_report.py` with these functions:

1. **`validate_job_completeness(job_id: str) -> dict`** (VALID-01, VALID-07):
   - Get job from backfill_jobs table via job manager
   - Calculate: total_items, completed_items, failed_items, coverage_pct, success_rate
   - Check if success_rate >= VALIDATION_THRESHOLDS["job_success_threshold"] (95%)
   - Check if all items accounted for (completed + failed == total)
   - Determine `expected_status`: 'complete' if success >= 95%, 'partial' if 0% < success < 95%, 'failed' if 0%
   - Return dict:
     ```python
     {
         "job_id": str,
         "valid": bool,  # all items accounted for AND success >= 95%
         "total_items": int,
         "completed_items": int,
         "failed_items": int,
         "unaccounted_items": int,  # total - completed - failed
         "coverage_pct": float,
         "success_rate": float,
         "expected_status": str,  # what status should be based on rate
         "actual_status": str,
         "status_correct": bool,  # actual matches expected
     }
     ```

2. **`correct_job_status(job_id: str) -> dict`** (VALID-07):
   - Call `validate_job_completeness(job_id)` to get completeness report
   - If `status_correct` is False (actual != expected), call `update_job_status(job_id, expected_status)` from job manager
   - Return dict: `{"job_id": str, "corrected": bool, "old_status": str, "new_status": str}`
   - This is the enforcement mechanism: if the processor set 'complete' but success was actually <95%, this corrects it to 'partial'
   - Log a warning when correction is needed: `f"Job {job_id} status corrected: {old} -> {new} (success_rate={rate}%)"`

3. **`get_freshness_report() -> dict`** (VALID-02):
   - Use supabase client to query freshness across 3 data types:
   - **Baselines**: Count performance_baselines where created_at < (now - 60 days), group by stale/fresh
   - **Search terms**: Count distinct master_sku in search_queries where fetched_at < (now - 7 days) vs fresh
     - NOTE: search_queries may not have fetched_at column. Check SCHEMA.md. If not present, use period_end as proxy for freshness (if period_end is old, data is stale)
   - **Keywords**: Count keyword_metrics where updated_at < (now - 30 days) vs fresh
   - Also query total distinct master_skus in variant_index for coverage denominator (expected ~2,784)
   - Count master_skus WITH baseline data vs WITHOUT
   - Return dict:
     ```python
     {
         "generated_at": str,  # ISO timestamp
         "total_skus": int,  # from variant_index
         "baselines": {
             "fresh_count": int,
             "stale_count": int,
             "missing_count": int,  # total_skus - (fresh + stale)
             "threshold_days": 60,
         },
         "search_terms": {
             "fresh_count": int,
             "stale_count": int,
             "missing_count": int,
             "threshold_days": 7,
         },
         "keywords": {
             "fresh_count": int,
             "stale_count": int,
             "threshold_days": 30,
         },
     }
     ```

4. **`detect_metric_outliers(metric_name: str = "avg_ctr", z_threshold: float = 3.0) -> dict`** (VALID-10):
   - Query performance_baselines for all records with the specified metric
   - Use numpy to calculate Z-scores: `np.abs(stats.zscore(values))` (import from scipy)
   - Flag records where Z-score > z_threshold as anomalous for manual review
   - Handle edge cases: fewer than 3 records returns empty outliers list
   - Return dict:
     ```python
     {
         "metric": str,
         "z_threshold": float,
         "total_records": int,
         "outlier_count": int,
         "outliers": [
             {
                 "master_sku": str,
                 "platform": str,
                 "value": float,
                 "z_score": float,
             }
         ],
         "distribution": {
             "mean": float,
             "std": float,
             "min": float,
             "max": float,
         }
     }
     ```
   - Import numpy and scipy at top of file. These are optional imports -- wrap in try/except with a flag `HAS_SCIPY = True/False`. If scipy not available, return `{"error": "scipy not installed", "outliers": []}`.

5. **`generate_full_quality_report(job_id: str | None = None) -> dict`** (combines all):
   - If job_id provided, include completeness check
   - Always include freshness report
   - Always include outlier detection for avg_ctr
   - Return combined dict with "completeness", "freshness", "outliers" keys
