Execute a two-part research task:

**Part A: Google Shopping Ranking Factor Research**

Conduct web research on Google Shopping ranking factors using WebSearch/WebFetch. Cover:
1. Google Shopping Graph signals (product data completeness, GTIN/MPN matching, pricing accuracy)
2. Feed quality hierarchy: title optimization, description quality, attribute completeness, product type depth, image quality
3. Account-level factors: bid strategy, impression share dynamics, historical CTR/conversion rate, campaign structure
4. External factors: seller ratings (150+ reviews threshold), domain authority, pricing competitiveness, product reviews
5. Recent algorithm changes (2025-2026): structured_title requirements for AI content, ECPC deprecation (March 2025), Shopping Graph expansion

Supplement with official Google docs (Merchant Center Help, Google Ads Help) and industry practitioner sources. Research must distinguish HIGH/MEDIUM/LOW confidence for each signal.

**Part B: Allied Brass Competitive Baseline Data**

Pull real data using available MCP tools and APIs:

1. **Auction Insights** — Use `mcp__google-ads-mcp__search` with GAQL query against `auction_insight_view` for Shopping campaigns (customer ID `6253381786`). Extract: impression share, overlap rate, outranking share for all competitors. If Auction Insights returns empty (impression share too low), document this as a critical finding — it means Allied Brass is barely entering auctions.

2. **Merchant Center diagnostics** — Use `mcp__merchant-api-devdocs__query_mapi_docs` to find the correct Merchant API query for product-level issues. Then query for: disapproved products, products with limited performance, missing recommended attributes. Note: GMC Merchant account ID may differ from Google Ads ID — if the query fails, document what's needed and flag as an open question for the user.

3. **Current campaign configuration** — Use `mcp__google-ads-mcp__search` to query: campaign type (Standard Shopping vs Performance Max), current bid strategy, daily budget, recent performance metrics. GAQL query against `campaign` resource with `advertising_channel_type = 'SHOPPING'`.

4. **Current feed quality sample** — Use `mcp__supabase__execute_sql` (load via ToolSearch first) to pull 5-10 sample product titles and descriptions from `generated_content` or `product_catalog` to establish baseline content quality. Also check `variant_index` for attribute completeness patterns.

**Part C: Compile Research Document**

Write `docs/research/google-shopping-ranking-factors.md` with these sections:
- Executive Summary (key findings in 5 bullets)
- Google Shopping Ranking Signal Taxonomy (feed-controllable, account-level, external — each with priority ranking)
- Allied Brass Current State (Auction Insights data, Merchant Center findings, campaign configuration)
- Identified Gaps (where Allied Brass falls short vs ranking factor best practices)
- Recommended Prompt Changes for Phase 20 (specific, actionable changes to title/description generation prompts based on ranking factors)
- Quick Wins vs Medium-Term vs Long-Term (categorized by timeline and expected impact)

Per user decision: categorize factors by TWO dimensions — (1) controllability AND (2) priority ranking by expected impact within each category.

Include the hypothesis framework from RESEARCH.md (H1-H7) and mark each hypothesis as CONFIRMED, PARTIALLY CONFIRMED, or UNCONFIRMED based on the data collected.
