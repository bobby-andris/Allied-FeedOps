  <action>
Create `scripts/spot_check_propagation.py` — a reusable Python script that compares Supabase approved_content against Google Sheets rows.

**SKU Selection (mix of criteria, 15-20 total):**

First, query Supabase to select the spot-check sample:
1. 5 recently published (last 30 days) — `publish_events WHERE status='success' AND action='publish' AND published_at > NOW() - INTERVAL '30 days'` ORDER BY published_at DESC
2. 5 older published (30-90 days) — same table, `published_at BETWEEN NOW() - INTERVAL '90 days' AND NOW() - INTERVAL '30 days'`
3. 3-5 high-value — join with `search_queries` to find SKUs with highest impression volume among published ones
4. 2-3 random — random sample from remaining published SKUs

If fewer than 15 published SKUs exist total, use all of them.

**For each selected master_sku:**

1. Fetch `approved_content` from `generated_content` WHERE `platform='google'` for both `content_type='title'` and `content_type='description'`
2. Fetch all `gmc_offer_id` values from `variant_index` for this master_sku
3. For each offer_id, look up the Google Sheets row (uppercase the offer ID: `shopify_us_` -> `shopify_US_`)
4. Compare title (column H) and description (column J) from Sheets against approved_content

**Google Sheets Access:**
- Use environment variables from `.env.vercel` (GOOGLE_SHEETS_CLIENT_EMAIL, GOOGLE_SHEETS_PRIVATE_KEY)
- Sheet ID: `1qMjCn1ZPlDd0R3TkTI0kDnX6tnApIHrnfAOWfJj_QEg`
- Sheet name: `SupplementalFeedData`
- Use `gspread` with service account credentials (or `google-auth` + `google-api-python-client` if gspread not available)

**Discrepancy Threshold:**
- MEANINGFUL: title or description content differs after whitespace normalization (strip, collapse multiple spaces)
- NOT MEANINGFUL: trailing whitespace only, HTML entity differences (`&amp;` vs `&`), newline normalization
- Normalize both sides before comparing: strip whitespace, collapse spaces, normalize HTML entities

**{FINISH_NAME} Bug Scope:**
Also run a SQL query to count how many `generated_content` rows contain the literal string `{FINISH_NAME}` in `approved_content`:
```sql
SELECT master_sku, platform, content_type
FROM generated_content
WHERE approved_content LIKE '%{FINISH_NAME}%';
```
Include this count in the results.
