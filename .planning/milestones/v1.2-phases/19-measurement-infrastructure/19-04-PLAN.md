  <action>
**Create `src/feedops/integrations/merchant_api.py`:**

A Merchant API client wrapper that:
1. Uses `google.auth.default()` for authentication (same service account pattern as Google Ads)
2. Calls the Merchant Reports API: `POST https://merchantapi.googleapis.com/reports/v1beta/accounts/{MC_ID}/reports:search`
3. Queries `product_view` for disapproved and limited products:
```
SELECT id, offer_id, title, aggregated_reporting_context_status, item_issues
FROM product_view
WHERE aggregated_reporting_context_status IN ('NOT_ELIGIBLE_OR_DISAPPROVED', 'ELIGIBLE_LIMITED')
```
4. Also query ALL products for overall status counts:
```
SELECT offer_id, aggregated_reporting_context_status
FROM product_view
```
5. Parses item_issues to extract: type.code, type.canonicalAttribute, severity.aggregatedSeverity, resolution
6. Normalizes offer_id to lowercase (CRITICAL per Pitfall 2 in research: Merchant API returns uppercase `shopify_US_`, DB uses lowercase)
7. Returns list of product status dicts ready for Supabase upsert

Read `FEEDOPS_MERCHANT_CENTER_ID` from environment variable. If not set, raise a clear error.

Use `httpx` or `requests` (already available in the pipeline) for REST calls rather than installing a new Python client library.

**Create `src/feedops/api/gmc_sync.py`:**

A FastAPI Router with:
- `POST /gmc/sync` — triggers a full sync:
  1. Call `query_disapproved_products()` from merchant_api.py
  2. For each product, look up `master_sku` from `variant_index` by matching on lowercase gmc_offer_id
  3. Bulk upsert results to `gmc_product_status` table with `on_conflict='gmc_offer_id'`
  4. Return summary: `{ synced_count, disapproved_count, limited_count, eligible_count }`

Use the `run_async_in_thread()` pattern from main.py for the actual sync work (per CLAUDE.md: "FastAPI BackgroundTasks are killed when containers scale to zero"). Return 202 Accepted immediately with a job ID.

**Register the router in `src/feedops/api/main.py`:**
- Import the gmc_sync router
- `app.include_router(gmc_sync_router, prefix="/gmc", tags=["gmc"])`
