```typescript
import { NextResponse } from 'next/server'
import { createServiceClient } from '@/lib/supabase/server'
import { getLabelTierPerformance, getExistingFunnelTerms, defaultDateWindow } from '@/lib/shopping-funnel/service'
import { decomposeSearchTerm } from '@/lib/optimization/query-intelligence'
import {
  computeTierDistributions,
  computeGlobalDistributions,
  scoreTerm,
  getCachedDistributions,
  buildHeroCallout,
} from '@/lib/optimization/tier-scoring'
import type { TermScore } from '@/lib/optimization/tier-scoring.types'

export const maxDuration = 60
```

**GET handler:**

1. Parse query params: `customLabel0` (optional filter), `range` (date range, default '30d'), `forceRefresh` (bypass cache)
2. Build date window from `defaultDateWindow(range)`
3. Fetch data in parallel:
   - `getLabelTierPerformance({ startDate, endDate, customLabel0 })`
   - `getExistingFunnelTerms({ startDate, endDate, customLabel0, tier: 'all', limit: 5000, offset: 0 })`
4. Compute distributions (use `getCachedDistributions` unless `forceRefresh=true`)
5. Compute global fallback distributions
6. Score each term:
   - Get intent features via `decomposeSearchTerm(term.search_term)`
   - Find the term's group distribution from the distributions map
   - Call `scoreTerm(term, groupDist, globalFallback, intentFeatures)`
7. Build hero callout from scores
8. Persist scores to `query_value_scores` — batch upsert in chunks of 500:
   ```typescript
   const supabase = createServiceClient()
   for (let i = 0; i < scores.length; i += 500) {
     const chunk = scores.slice(i, i + 500)
     await supabase.from('query_value_scores').upsert(
       chunk.map(s => ({
         search_term: s.searchTerm,
         custom_label_0: s.customLabel0,
         score_version: 'v2-tier-scoring',
         tier_fit_scores: s.tierFitScores,
         recommended_tier: s.recommendedTier,
         net_monthly_impact: s.impact?.mid ?? 0,
         scored_at: new Date().toISOString(),
         // Preserve existing columns with reasonable defaults
         expected_clicks: 0,
         expected_cvr: 0,
         expected_conversion_value: 0,
         expected_profit_proxy: 0,
         uncertainty: 1 - s.confidence.score,
         impact_score: s.impact?.mid ?? 0,
         model_inputs: {
           confidence: s.confidence,
           fallbackLevel: s.fallbackLevel,
           currentTier: s.currentTier,
         },
       })),
       { onConflict: 'search_term,custom_label_0' }
     )
   }
   ```
9. Return JSON response:
   ```typescript
   return NextResponse.json({
     distributions: Object.fromEntries(distributions),  // Map → object for JSON
     globalFallback,
     scores,
     heroCallout,
     computedAt: new Date().toISOString(),
     totalGroups: distributions.size,
     totalTermsScored: scores.length,
     totalMisplaced: scores.filter(s => s.isMisplaced).length,
     totalImpact: aggregateImpact(scores),
   })
   ```

**Error handling:**
- Wrap in try/catch, return 500 with `{ error: message }` on failure
- If `getLabelTierPerformance` returns 0 rows, return 200 with empty distributions and a message: "No tier performance data available"

**Helper: `aggregateImpact(scores: TermScore[]): ImpactRange`**
- Sum low/mid/high across all misplaced terms
- Return the aggregate ImpactRange
