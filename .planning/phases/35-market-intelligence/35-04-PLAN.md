**Main Page (`page.tsx`):**

'use client' component. Full implementation:

1. **State:**
   - `activeTab: 'demand' | 'competitive' | 'products'` — default 'demand'
   - `customLabel0Filter: string | undefined` — shared filter across all tabs
   - `customLabel0Options: string[]` — populated from API or hardcoded list

2. **Filter bar (above tabs):**
   - Label: "Product Group:" followed by a Select dropdown
   - Options: "All Groups" (default, undefined) + sorted list of custom_label_0 values
   - To get the list: fetch `/api/market-intelligence/products` on mount, extract unique customLabel0 values from response, or maintain a simple const of known groups
   - Simpler approach: hardcode "All Groups" as default. The tab hooks already handle undefined customLabel0. Populate options lazily from the first API response that returns data.

3. **Tabs:**
   - Use shadcn Tabs component with `value={activeTab}` and `onValueChange`
   - TabsList with 3 triggers: "Demand", "Competitive", "Products"
   - Each TabsContent renders the corresponding tab component with `customLabel0={customLabel0Filter}`

4. **Page header:**
   ```tsx
   <div className="flex items-center justify-between">
     <div>
       <h1 className="text-2xl font-bold">Market Intelligence</h1>
       <p className="text-muted-foreground">Demand patterns, competitive positioning, and product group health</p>
     </div>
     <Select value={customLabel0Filter ?? 'all'} onValueChange={v => setCustomLabel0Filter(v === 'all' ? undefined : v)}>
       <SelectTrigger className="w-[200px]">
         <SelectValue placeholder="All Groups" />
       </SelectTrigger>
       <SelectContent>
         <SelectItem value="all">All Groups</SelectItem>
         {customLabel0Options.map(g => <SelectItem key={g} value={g}>{g}</SelectItem>)}
       </SelectContent>
     </Select>
   </div>
   ```

5. **Product group options loading:**
   - On mount, fetch the product groups to populate the filter dropdown
   - Simple approach: separate small fetch to `/api/market-intelligence/products` just to get the group names
   - Store in state, sorted alphabetically

6. **Layout:**
   ```tsx
   <div className="space-y-6 p-6">
     {/* Header + Filter */}

     <Tabs value={activeTab} onValueChange={(v) => setActiveTab(v as any)}>

         <TabsTrigger value="demand">Demand</TabsTrigger>
         <TabsTrigger value="competitive">Competitive</TabsTrigger>
         <TabsTrigger value="products">Products</TabsTrigger>
   ```
