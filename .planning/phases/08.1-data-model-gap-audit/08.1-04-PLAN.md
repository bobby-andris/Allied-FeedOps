  <name>Task 1: Create bulk baseline backfill script with test gate</name>
  <files>scripts/bulk_baseline_backfill.py</files>
  <action>
    Create `scripts/bulk_baseline_backfill.py` following RESEARCH.md Pattern 4:

    **Structure:**
    - CLI entry point with argparse: `--test-gate` (50 SKUs only), `--dry-run` (list SKUs, don't call API), `--batch-size` (default 50), `--sleep` (default 2.0 seconds)
    - Published SKUs first (have entries in `publish_events`), then remaining by `master_sku` sort
    - Uses existing `_capture_google_baseline()` from `performance_baseline.py` for each SKU
    - Throttling: process BATCH_SIZE SKUs, sleep SLEEP_BETWEEN_BATCHES seconds, repeat

    **Key behaviors per locked decisions:**
    1. **Published first**: Query `SELECT DISTINCT master_sku FROM publish_events` for priority ordering
    2. **50-SKU test gate**: `--test-gate` flag processes only first 50 SKUs and prints summary (offer ID match rate, time per batch, rows inserted)
    3. **Zero baselines**: When `_capture_google_baseline()` returns empty/no data, explicitly upsert a zero baseline to `performance_baselines` with `metadata: {"zero_baseline": true, "reason": "no_google_ads_data"}` -- per locked decision "Store zero baselines explicitly"
    4. **Variant baselines**: For each master_sku, also capture variant-level baselines by querying variant_index for offer IDs, then storing per-offer-ID averages in `performance_baselines_variant`
    5. **Progress logging**: Print batch N/total, SKUs processed, time elapsed after each batch
    6. **Error handling**: Log errors per-SKU but continue processing (don't abort batch on single failure)

    **Quota calculation (document in script docstring):**
    - ~2,500 SKUs x ~28 variants = ~70,000 offer IDs
    - `fetch_batch_product_performance()` chunks at 25 offer IDs per GAQL request
    - ~2,800 GAQL requests total; well within 14,400/day quota
    - 50-SKU test gate: ~56 GAQL requests (safe)

    **Usage in docstring:**
    ```
    # Test gate first (MANDATORY before full sweep):
    PYTHONPATH=./src python scripts/bulk_baseline_backfill.py --test-gate

    # Dry run (list SKUs without API calls):
    PYTHONPATH=./src python scripts/bulk_baseline_backfill.py --dry-run

    # Full sweep (only after test gate approved):
    PYTHONPATH=./src python scripts/bulk_baseline_backfill.py
    ```

    The script must be runnable standalone with `PYTHONPATH=./src` and env vars loaded from `.env.vercel` (standard pattern for scripts/).
