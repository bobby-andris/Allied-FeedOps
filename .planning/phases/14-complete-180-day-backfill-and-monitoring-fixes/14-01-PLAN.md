    Read the file. There are exactly 2 GAQL queries that use `LAST_{days}_DAYS`:

    1. In `_fetch_campaign_products` (around line 486):
       ```
       WHERE segments.date DURING LAST_{days}_DAYS
       ```
       Replace with explicit BETWEEN using today's date minus `days`:
       ```python
       # At the top of the method, before the query:
       end_date = date.today().strftime("%Y-%m-%d")
       start_date = (date.today() - timedelta(days=days)).strftime("%Y-%m-%d")
       ```
       Then change the WHERE clause to:
       ```
       WHERE segments.date BETWEEN '{start_date}' AND '{end_date}'
       ```
       Note: `date` and `timedelta` are already imported at the top of the file (line 17).

    2. In `fetch_search_terms` (around line 566):
       ```
       WHERE segments.date DURING LAST_{days}_DAYS
       ```
       Same fix — compute `end_date` / `start_date` at the top of that method and use BETWEEN.

    For both methods: use f-string interpolation since the query is already an f-string.
