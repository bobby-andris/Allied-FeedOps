Create a Google Sheet for blind human scoring. Two approaches depending on credential availability:

**Sheet structure — 3 tabs (Google, Bing, Shopify):**
Each tab has these columns:
| SKU | Output A Title | Output A Description | Output B Title | Output B Description | Output C Title | Output C Description | Bobby Pass/Fail A | Bobby Notes A | Bobby Pass/Fail B | Bobby Notes B | Bobby Pass/Fail C | Bobby Notes C | Robert Pass/Fail A | Robert Notes A | Robert Pass/Fail B | Robert Notes B | Robert Pass/Fail C | Robert Notes C |

- Populate Output A/B/C from pass-1 content in raw_results.csv
- Randomly assign providers to A/B/C labels (consistent per SKU within a platform, but randomized across SKUs to prevent pattern detection)
- Store the provider->label mapping in `docs/evaluation/blind_scoring_sheet.md` (NOT in the sheet itself)
- Share sheet with bobby.andris@avondaledecor.com

**Also include in the sheet:**
- Header row with scoring instructions: "Score each output Pass/Fail. Consider: title quality, description quality, brand voice accuracy, factual accuracy. Add freeform notes for notable strengths/weaknesses."
- If SKUs have approved_content, add a "Reference (Previously Approved)" column for context (not scored, just reference)
