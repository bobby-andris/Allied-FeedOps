<decisions_made>

- **Timeout architecture**: Removed SDK timeout (was 45s OpenAI / 60s Claude) and provider max_total_seconds (was 120s). Kept only executor asyncio.wait_for as single source of truth, bumped to 120s. Rationale: three competing timeout layers caused the GPT-5.2 failures on complex SKUs — SDK killed legitimate requests at 45s when GPT-5.2 with high reasoning legitimately needs 30-45s.
- **Retryable errors**: Added "529" and "overloaded" to reliability.py. Anthropic 529 overloaded was NOT being retried because the classifier only checked for "service unavailable" not "overloaded".
- **Model recommendation (from blind eval)**: Claude Sonnet 4.6 scored 8.85/10 (best quality + lowest cost at $0.008/call). Claude Opus 4.6 scored 8.00/10 ($0.013/call). GPT-5.2 scored 6.15/10 (worst quality at highest cost $0.034/call). Sonnet recommended as primary for 95% of SKUs.
- **Data sufficiency**: 222 rows (9 SKUs) is enough for blind scoring. User confirmed.
</decisions_made>
