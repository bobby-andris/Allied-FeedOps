### Task 2: Go-live configuration
**What to deploy on Cloud Run:**

```bash
# Add to Cloud Run env vars:
FEEDOPS_PROVIDER=claude
ANTHROPIC_API_KEY=[from GCP secret feedops-anthropic-api-key]
FEEDOPS_CLAUDE_MODEL=claude-sonnet-4-6
FEEDOPS_GOOGLE_BRIEF_VERSION=v3  # if skill prompt approved

# Keep existing (fallback):
OPENAI_API_KEY=[unchanged]
```

Steps:
1. Create GCP secret `feedops-anthropic-api-key` if not exists
2. Bind secret to runtime SA
3. Update Cloud Run env vars
4. Deploy and verify with `/health` endpoint
5. Test with curl: `POST /optimize-sku` for one known SKU
6. Verify output quality matches evaluation results

### Task 3: Rollback procedure

Document in recommendation.md:
```
# Rollback to GPT-5.2
gcloud run services update feedops-pipeline \
  --set-env-vars="FEEDOPS_PROVIDER=openai" \
  --project=bobbys-project-346400
```

Rollback is instant — just change env var. No code changes needed.
