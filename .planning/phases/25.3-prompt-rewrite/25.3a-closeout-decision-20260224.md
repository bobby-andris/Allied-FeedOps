## What Was Broken

### Primary: Prompt Contract Drift
The committed `scripts/ab_prompt_test.py` imported `build_core_prompt` — the v1 legacy prompt builder that injects `"Product Evidence Table:\n{evidence_markdown}"` as a raw string prefix. The v2 per-platform builders (`build_google_prompt`, `build_bing_prompt`, `build_shopify_prompt`) use XML-tagged `<evidence_table>` sections that GPT-5.2 parses correctly.

This drift meant test runs appeared to use v2 prompts (the system prompt was v2) but the user prompt was built with v1 code, creating a v1/v2 hybrid that GPT-5.2 could not parse consistently.

### Secondary: Missing Test Guardrails
No test existed to prevent `build_core_prompt` from being imported in v2 code paths. The drift was invisible because test runs still produced output — just with degraded constraint adherence.

## What Was Fixed

### Code Changes (commits `97277291`, `a3134e31`)
1. **`ab_prompt_test.py`** — replaced `from feedops.api.prompt_builder import build_core_prompt` with imports of `build_google_prompt`, `build_bing_prompt`, `build_shopify_prompt`
2. **`build_user_prompt()`** — now delegates to platform-specific builders with proper evidence coercion, keyword enrichment, and XML tag wrapping
3. Added retry logic, JSON content-wrapper unwrapper, meta-search commentary detection, customer-content-only banned word checks
4. **2 static guardrail tests** that fail if `build_core_prompt` appears in `generator.py` or `ab_prompt_test.py` source code

### Prior Foundation (commits `5933c906`, `ad68f85c`)
- Cherry-picked JSON parser, skill sanitizer, reasoning tuning from Codex
- Rewrote all 4 platform prompts as GPT-5.2 creative briefs with XML structure
- Reduced system prompt from 57K (skill dump) to ~8-10K (distilled brief)
