# v1.3a Closeout Note — Content Generation Excellence

## Final Contract (Implemented)
1. Single quality contract alignment:
- Platform briefs now encode explicit must-do/never-do rules from human evaluation.
- Hard bans include:
  - competitor mentions in customer-facing copy
  - keyword-list phrasing (`also searched as` style)
  - weight-capacity messaging for standard categories
  - banned promo words (`finest`, `luxurious`, `premium`, `exclusive`, `exceptional`, `unparalleled`, `superior`, `exquisite`, `ultimate`)
- Category noun fidelity in titles:
  - towel-bar categories must use `Towel Bar` (not `Towel Rack`) in Google/Bing titles.

2. Prompt-context sanitization:
- Competitor brands stripped from keyword/search evidence before prompt assembly.
- Banned prose words stripped from catalog-derived narrative evidence.
- Placeholders (`{FINISH_NAME}`, `{FINISH_SENTENCE}`) preserved exactly.
- Source-of-truth data in DB remains unchanged.

3. Schema de-confliction:
- Removed description `maxLength`/`pattern` constraints that caused empty JSON failures.
- Kept platform-enforced hard maxes:
  - `google_title <= 150`
  - `google_short_title <= 70`
  - `shopify_meta_description <= 160`

4. Reliability + diagnostics:
- `reasoning_effort` defaults to `high` on v2 runtime and harness paths.
- Quality-safe completion ceiling defaults to `8000`.
- Per-platform retry with backoff for transient/strict-json failures.
- Failure diagnostics include `finish_reason`, `refusal`, raw response length, and token usage where available.
- Retry scope is per-platform (no whole-batch reruns).

5. Deterministic unseen readiness gate:
- `scripts/batch_ab_test.py` supports deterministic unseen sampling:
  - `--unseen-count`
  - `--unseen-seed` (default `52`)
- Unseen pool definition:
  - `product_catalog - generated_content - canonical_10`
- Mode-specific summary artifacts prevent canonical/unseen overwrite.
