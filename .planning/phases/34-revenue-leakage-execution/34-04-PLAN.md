## Goal
Wire everything together: add Revenue Leakage and History tabs to the page, update Action Queue to show approved items with undo capability, enable the "Apply Recommendations" button on HeroSummary, and build the History tab with day-grouped entries. This completes the full Phase 34 feature set.

## Context
- Current page.tsx has 2 tabs: Action Queue, Explorer (from Phase 33.2). We add 2 more: Revenue Leakage, History. Total: 4 tabs.
- **Tab clarification**: CONTEXT.md mentions `[Scoring]` in the tab list, but the current page IS the Tier Scoring page — "Scoring" refers to the page itself, not a separate tab. Explorer is an existing tab from Phase 33.2 that must be preserved. Final tab order: `[Action Queue] [Explorer] [Revenue Leakage · N] [History]`.
- Revenue Leakage tab label shows badge count of actionable items
- Approved items flow: Revenue Leakage (pending) → approve → Action Queue (accepted) → undo → back to Revenue Leakage
- History tab reads from routing_recommendations via useRecommendations.loadHistory()
- History grouped by day, reverse chronological, shows term + action type + tier movement + timestamp
- HeroSummary currently has a disabled "Apply Recommendations" button with tooltip "Coming in Phase 34"

### Partial Requirement Coverage Notes
- **EXEC-03 (Undo)**: Phase 34 delivers the status-revert portion only (`accepted` → `pending` in routing_recommendations). The full EXEC-03 spec mentions `negative_registry` audit trail and criterion IDs — that integration requires actual Google Ads execution, which is Phase 36 scope. Phase 34 undo is safe because no Google Ads changes happen until Phase 36.
- **EXEC-04 (History)**: Phase 34 reads history from `routing_recommendations` (using the `metadata.history` array and `accepted_at`/`review_status` fields), NOT from `policy_action_execution_log` (PAEL). PAEL tracks actual Google Ads execution events and will be populated in Phase 36. Until then, `routing_recommendations` is the sole history source for the decision layer.

<task id="34-04-02b" title="Wire page.tsx with all 4 tabs (Revenue Leakage + History)" autonomous="true">
### What

**Update page.tsx** — Add Revenue Leakage and History tabs:

1. Import new components: `LeakageHero`, `RoasBoxPlot`, `LeakageTermList`, `BatchApproveBar`, `HistoryView`
2. Import hooks: `useRecommendations`
3. Import utilities: `classifyAllTerms` from `lib/reason-codes`
4. Add new icons: `DollarSign`, `Clock` from lucide-react

5. Initialize `useRecommendations` hook at the top of the component:
   ```typescript
   const recommendations = useRecommendations()
   ```

6. Compute classified terms using `useMemo`:
   ```typescript
   const classifiedTerms = useMemo(() => {
     if (!data) return []
     return classifyAllTerms(data.scores)
   }, [data])

   const pendingTerms = useMemo(() => {
     return classifiedTerms.filter(t => {
       const status = recommendations.getStatus(t.searchTerm, t.customLabel0)
       return !status || status.status === 'pending' || status.status === 'rejected'
     })
   }, [classifiedTerms, recommendations])

   const highConfidenceCount = useMemo(() => {
     return pendingTerms.filter(t => t.confidence.score > 0.80).length
   }, [pendingTerms])

   const avgConfidence = useMemo(() => {
     if (pendingTerms.length === 0) return 0
     return pendingTerms.reduce((sum, t) => sum + t.confidence.score, 0) / pendingTerms.length
   }, [pendingTerms])
   ```

7. Add a `tabRef` to control active tab programmatically:
   ```typescript
   const [activeTab, setActiveTab] = useState('actions')
   ```
   Use `<Tabs value={activeTab} onValueChange={setActiveTab}>` instead of `defaultValue`.

8. Tab structure (4 tabs):
   ```tsx
   <TabsList>
     <TabsTrigger value="actions" className="gap-1.5">
       <LayoutList className="h-3.5 w-3.5" />
       Action Queue
     </TabsTrigger>
     <TabsTrigger value="explorer" className="gap-1.5">
       <Search className="h-3.5 w-3.5" />
       Explorer
     </TabsTrigger>
     <TabsTrigger value="leakage" className="gap-1.5">
       <DollarSign className="h-3.5 w-3.5" />
       Revenue Leakage
       {pendingTerms.length > 0 && (
         <span className="ml-1 rounded-full bg-amber-100 text-amber-800 px-1.5 py-0.5 text-xs font-medium">
           {pendingTerms.length}
         </span>
       )}
     </TabsTrigger>
     <TabsTrigger value="history" className="gap-1.5">
       <Clock className="h-3.5 w-3.5" />
       History
     </TabsTrigger>
   </TabsList>
   ```

9. Revenue Leakage tab content:
