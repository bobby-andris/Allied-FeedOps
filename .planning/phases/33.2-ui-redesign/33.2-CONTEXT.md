# Phase 33.2: Tier Intelligence UI Redesign

## Problem Statement

The Phase 33 Tier Intelligence page has solid infrastructure (scoring engine, API, persistence, 4-level drill-down) but the UI is built for data scientists, not for the business owner (Robert) or operator (Bobby) who need to make decisions.

**Deferred until after Phase 33.1** — calibration must produce trustworthy numbers before redesigning the presentation. No point making a beautiful UI that shows garbage data.

## Current State (Phase 33)

- 4-level statistical drill-down: Groups → Group → Tier → Term
- Shows p25/p50/p75, z-scores, MAD, confidence factors with 30/30/20/20 weighting
- Hero callout with misplaced count and dollar impact
- Group cards with tier ROAS, term counts, fallback indicators
- Distribution charts with Recharts horizontal bars
- Expandable scorecard factors revealing math

## What's Wrong

1. **No actionable decisions** — can't move terms, can't apply recommendations, can't export
2. **Speaks statistician** — z-scores, MAD, p25/p50/p75 mean nothing to Robert
3. **No prioritization** — 4,064 "misplaced" terms with no way to know which 10 matter most
4. **No before/after** — no comparison to show what changes if recommendations are followed
5. **No connection to operations** — doesn't link to Google Ads campaign changes

## Target Experience

### For Robert (business owner, 2 min/week):
One card: "You're spending $X/month on search terms that aren't converting well in their current tier. Here are the top 10 terms where moving them could save you $Y/month. [Apply Recommendations]"

### For Bobby (operator, 10 min/week):
- Action queue: 10-20 terms sorted by dollar impact
- Clear arrows: HIGH→MEDIUM, LOW→MEDIUM
- One-click apply (or batch apply)
- Undo capability
- Weekly email digest: "3 terms moved this week, net impact: +$180/mo"

## Design Principles

1. **Actions first, data second** — the page exists to help make decisions, not explore statistics
2. **Plain English** — "This term earns 2x return but costs you premium placement" not "z-score: -1.3"
3. **Prioritized** — show the 10 highest-impact items, not all 4,000
4. **Connected** — link to actual campaign changes (Phase 34 handles execution)
5. **Progressive disclosure** — summary first, details on demand (keep the 4-level drill-down but hide it behind "Show details")

## Relationship to Phase 34

Phase 34 (Revenue Leakage and Execution) builds the execution layer (one-click tier movements, undo, persistence). Phase 33.2 redesigns the *presentation* layer. They complement each other:
- 33.2: Makes insights digestible and prioritized
- 34: Makes insights actionable with execution buttons

Consider merging 33.2 into Phase 34 planning if the scope overlaps significantly.

## Expected Outputs

- Redesigned Tier Intelligence page focused on action queue
- Hero card with clear dollar opportunity and "Apply" CTA
- Top-N prioritized misplaced terms (not all 4,000)
- Plain English verdicts replacing statistical jargon
- Statistical details preserved but behind progressive disclosure
- Build passes, visual verification approved
