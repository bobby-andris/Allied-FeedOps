Create a Supabase migration file that creates two tables:

**Table: backfill_jobs**
```sql
CREATE TABLE backfill_jobs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  job_type TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'creating',
  total_items INTEGER NOT NULL,
  completed_items INTEGER DEFAULT 0,
  failed_items INTEGER DEFAULT 0,
  skus JSONB,                    -- Array of SKU strings to process
  checkpoint_data JSONB,         -- { "batch_index": 50, "last_sku": "920D-6" }
  config JSONB DEFAULT '{}',     -- Job config: { "batch_size": 10, "days_lookback": 180 }
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  started_at TIMESTAMPTZ,
  completed_at TIMESTAMPTZ,
  eta_seconds INTEGER,
  created_by TEXT
);
```

Add constraints:
- `CHECK (status IN ('creating', 'running', 'complete', 'failed', 'partial'))`
- `CHECK (job_type IN ('search_terms', 'performance_metrics', 'keyword_planner', 'custom_labels', 'full_backfill'))`

Add indexes:
- `idx_backfill_jobs_status` on `(status, created_at DESC)`
- `idx_backfill_jobs_type` on `(job_type, created_at DESC)`

**Table: backfill_job_errors**
```sql
CREATE TABLE backfill_job_errors (
  id BIGSERIAL PRIMARY KEY,
  job_id UUID NOT NULL REFERENCES backfill_jobs(id) ON DELETE CASCADE,
  item_id TEXT NOT NULL,
  error_type TEXT NOT NULL,
  error_message TEXT,
  retry_count INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

Add indexes:
- `idx_backfill_job_errors_job` on `(job_id, created_at DESC)`

Add a comment at the top explaining these tables support the v1.0 data backfill infrastructure.

Also create an RPC function for atomic failure count increment:
```sql
CREATE OR REPLACE FUNCTION increment_backfill_failures(p_job_id UUID)
RETURNS VOID AS $$
BEGIN
  UPDATE backfill_jobs
  SET failed_items = COALESCE(failed_items, 0) + 1
  WHERE id = p_job_id;
END;
$$ LANGUAGE plpgsql;
```

**Create `src/feedops/jobs/manager.py`:**
Implements job CRUD using `get_client()` from `feedops.db.supabase_client`. Use the `@_with_retry` decorator pattern from supabase_client (import `_with_retry` or re-implement locally for job operations).

Functions to implement:

1. `create_job(job_type: str, skus: list[str], config: dict | None = None, created_by: str | None = None) -> str`:
   - Insert into backfill_jobs with status='creating', total_items=len(skus), skus as JSONB array
   - Return the job_id (UUID string)

2. `get_job(job_id: str) -> BackfillJob | None`:
   - Select from backfill_jobs by id
   - Return BackfillJob model or None

3. `get_active_jobs() -> list[BackfillJob]`:
   - Select where status IN ('creating', 'running')
   - Order by created_at ASC

4. `get_active_job_count() -> int`:
   - COUNT where status IN ('creating', 'running')

5. `update_job_status(job_id: str, status: str, completed_at: datetime | None = None) -> None`:
   - Update status field
   - If status is 'running', set started_at to NOW if not already set
   - If status is 'complete', 'failed', or 'partial', set completed_at

6. `update_job_progress(job_id: str, completed_items: int, total_items: int, started_at_epoch: float) -> None`:
   - Calculate ETA: elapsed = time.time() - started_at_epoch; rate = completed / elapsed; remaining = total - completed; eta = remaining / rate
   - Update completed_items and eta_seconds
   - Handle edge cases: if elapsed <= 0 or rate <= 0, set eta_seconds to None

7. `save_checkpoint(job_id: str, checkpoint_data: dict) -> None`:
   - Update checkpoint_data JSONB field on backfill_jobs

8. `log_job_error(job_id: str, item_id: str, error_type: str, error_message: str, retry_count: int = 0) -> None`:
   - Insert into backfill_job_errors (truncate error_message to 500 chars)
   - Call RPC `increment_backfill_failures` to atomically increment failed_items

9. `get_job_errors(job_id: str, limit: int = 100) -> list[JobError]`:
   - Select from backfill_job_errors ordered by created_at DESC

All functions should use `get_client()` from `feedops.db.supabase_client`. Follow the existing pattern of importing it at function call time (not module level) for testability.
