Create `dashboard/src/app/api/funnel-snapshots/trends/route.ts`:

GET handler that queries funnel_snapshots_daily for 7-day vs previous-7-day aggregates:

- Use `createAdminClient()` from `@/lib/supabase/admin`
- Query `.from('funnel_snapshots_daily').select('*')` with date filters: `.gte('snapshot_date', fifteenDaysAgo).lte('snapshot_date', yesterday)`
- Compute yesterday and fifteenDaysAgo in UTC (same pattern as capture route)
- Group rows into "current" (last 7 days: yesterday through 7 days ago) and "previous" (prior 7 days) in TypeScript
- Compute aggregates for each period: sum impressions, clicks, cost_micros, conversions, conversions_value
- Compute derived metrics:
  - CTR = clicks / impressions (guard division by zero, default 0)
  - ROAS = conversions_value / (cost_micros / 1e6) (guard division by zero, default 0)
- Return JSON shape:
```typescript
{
  current: { impressions, clicks, ctr, cost_micros, conversions, conversions_value, roas },
  previous: { impressions, clicks, ctr, cost_micros, conversions, conversions_value, roas } | null,
  has_data: boolean,  // false if zero rows total
  has_previous: boolean  // false if no rows in previous period
}
```
- If zero rows exist at all, return `{ has_data: false, ... }` with zeroed metrics
- Set `Cache-Control: public, s-maxage=3600` header (trends update once daily)
- Wrap in try/catch, return 500 with error message on failure
  </action>

Create `dashboard/src/app/(dashboard)/shopping-funnel/FunnelTrendCards.tsx`:

A self-contained `'use client'` component that:
- Fetches from `/api/funnel-snapshots/trends` on mount via useEffect
- Renders nothing (null) if `has_data === false` (cards hidden per CONTEXT.md)
- Renders 6 cards in a responsive grid: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-4`
- Row 1: Impressions, Clicks, CTR
- Row 2: Ad Spend (cost_micros / 1e6, formatted as $X,XXX), Conversions, ROAS

Each card structure (use shadcn Card):
```
[Card]
  [CardHeader compact]
    Title: metric name (text-sm font-medium text-muted-foreground)
  [CardContent]
    Value: large number (text-2xl font-bold)
    Trend: TrendArrow component showing direction + percentage
[/Card]
```

TrendArrow sub-component (inline in same file):
- Takes `current: number`, `previous: number`, `invertColor?: boolean` (true for Ad Spend where down=good)
- If `has_previous` is false: render `<span className="text-xs text-muted-foreground">No prior data</span>`
- If previous is 0: render "No prior data"
- Compute pctChange = ((current - previous) / previous) * 100
- If abs(pctChange) <= 5: render Minus icon with muted color (flat)
- If pctChange > 5: TrendingUp icon, green (or red if invertColor)
- If pctChange < -5: TrendingDown icon, red (or green if invertColor)
- Show percentage: `+X.X%` or `-X.X%`

Import icons from lucide-react: TrendingUp, TrendingDown, Minus (already used in project).

Number formatting:
- Impressions, Clicks: Intl.NumberFormat with no decimals
- CTR: percentage with 2 decimals (e.g., "2.45%")
- Ad Spend: Intl.NumberFormat currency USD (e.g., "$1,234")
- Conversions: 1 decimal
- ROAS: 2 decimals with "x" suffix (e.g., "3.42x")

Loading state: Show Skeleton components inside cards while fetching.

Follow the same visual pattern as the Overview page's metric cards. Match existing dashboard card styling conventions.
