<task type="auto">
  <name>Task 1: Query Google Ads API for conversion actions, CPC caps, and CPA</name>
  <files>docs/analysis/google-ads-account-audit.md</files>
  <action>
    Use Google Ads MCP tools to query the account (customer ID: 6253381786). Run these queries:

    1. **Conversion actions catalog**: Query `conversion_action` resource to list all 19 conversion actions:
       ```
       SELECT conversion_action.name, conversion_action.type, conversion_action.category,
              conversion_action.status, conversion_action.counting_type,
              conversion_action.include_in_conversions_metric
       FROM conversion_action
       WHERE conversion_action.status = ENABLED
       ```
       Classify each as: purchase, add-to-cart, page-view, begin-checkout, or other micro-conversion.
       Identify which ones have `include_in_conversions_metric = true` (these are "conversions") vs false (these contribute to "all_conversions" only).

    2. **Average CPA**: Query campaign-level metrics for the last 90 days:
       ```
       SELECT campaign.name, metrics.cost_micros, metrics.conversions, metrics.all_conversions
       FROM campaign
       WHERE campaign.advertising_channel_type = SHOPPING
         AND campaign.status = ENABLED
         AND segments.date DURING LAST_90_DAYS
       ```
       Compute: total cost / total conversions = avg CPA. Also compute total cost / total all_conversions for micro-CPA.

    3. **CPC caps per ad group** (HIGH tier campaigns):
       ```
       SELECT campaign.name, ad_group.name, ad_group.cpc_bid_micros
       FROM ad_group
       WHERE campaign.advertising_channel_type = SHOPPING
         AND campaign.status = ENABLED
         AND ad_group.status = ENABLED
       ```
       Document the Max CPC cap for each HIGH tier ad group (grouped by custom_label_0).

    4. **Behavioral signal availability test**: Query a small sample from search_term_view with extended metrics:
       ```
       SELECT search_term_view.search_term, metrics.impressions, metrics.clicks,
              metrics.average_cpc, metrics.all_conversions, metrics.conversions,
              metrics.cross_device_conversions
       FROM search_term_view
       WHERE campaign.advertising_channel_type = SHOPPING
         AND segments.date DURING LAST_30_DAYS
       LIMIT 10
       ```
       Verify which fields return data. Note: `cross_device_conversions` may not be available on search_term_view.

    5. **Campaign impression share**: Query campaign-level impression share:
       ```
       SELECT campaign.name, metrics.search_impression_share
       FROM campaign
       WHERE campaign.advertising_channel_type = SHOPPING
         AND campaign.status = ENABLED
         AND segments.date DURING LAST_30_DAYS
       ```

    Write all findings to `docs/analysis/google-ads-account-audit.md` with:
    - Conversion actions table (name, type, category, in_conversions)
    - Average CPA calculation
    - CPC caps per product group
    - Behavioral signal availability matrix
    - Recommended wasted spend threshold (1.5x avg CPA)
  </action>
