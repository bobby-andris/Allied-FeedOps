  <action>
    1. Fetch 1000+ search terms with performance data from the Google Ads API or from the existing scored results in the dashboard.
       Use the scores API endpoint: `GET /api/shopping-funnel/scores?limit=3000` to get terms with their current scoring.

    2. For each term, record:
       - search_term
       - current_tier (HIGH/MEDIUM/LOW)
       - intent_score (unified)
       - feed_alignment_score
       - behavioral_score
       - actual ROAS
       - conversions
       - impressions
       - spend

    3. Analysis:
       a. **Intent score vs ROAS correlation**: Plot/tabulate intent score buckets (0-0.25, 0.25-0.50, 0.50-0.65, 0.65-0.85, 0.85-1.0) against average ROAS per bucket
       b. **Threshold validation**: For the 0.65 promote threshold:
          - How many terms score >= 0.65?
          - What percentage of those have ROAS > tier p75? (true positives)
          - What percentage have ROAS < tier p25? (false positives — would promote bad terms)
       c. **Zero-conversion term analysis**: Among terms with 0 conversions:
          - How many score >= 0.65? (candidates for Trigger D)
          - How many of those have rCTR >= 1.5 OR wordCount >= 3? (pass the gate)
          - What is their micro-conversion rate? (validation signal)
       d. **Wasted spend threshold**: Using real avgCPA from audit:
          - How many terms exceed 1.5x avgCPA with 0 conversions?
          - What's the total spend on these terms?
          - Compare against the hardcoded $5 threshold

    4. Write findings to `docs/analysis/intent-score-calibration.md` with:
       - Data summary (N terms, date range, tiers represented)
       - Intent score distribution histogram
       - ROAS correlation table
       - Threshold recommendations (keep 0.65 or adjust)
       - Wasted spend threshold recommendation
       - False positive/negative rates
       - Recommendations for weight adjustments (0.55/0.45 split)
