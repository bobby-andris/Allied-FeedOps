## Decisions Made
- Wasted spend threshold should be $96.33 (1.5x avg CPA) — the current $5 threshold flags nearly every term with any spend as wasted
- CPC ceiling pressure signal cannot use ad_group.cpc_bid_micros (all $0.01 due to Target ROAS) — must use metrics.average_cpc from search_term_view
- Only 1 of 19 conversion actions is a purchase — `metrics.conversions` is purchase-only, `metrics.all_conversions` includes 18 micro-conversions (58.6x multiplier)
- All 6 behavioral signals confirmed available on search_term_view — cross_device_conversions often 0.0 but returns data
- User acknowledged additional competitive metrics available from API for future Supabase migration
