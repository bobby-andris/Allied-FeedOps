<objective>
Add behavioral intent signals to the tier-scoring pipeline by extending the Google Ads GAQL query to fetch average_cpc and all_conversions, then computing rCTR, CPC ceiling pressure, and micro-conversion delta in the scoring engine.

Purpose: This is Domain B of the dual-domain intent scoring system. It answers "What does Google Ads data tell us about this query's intent?" Three signals give confidence that a zero-conversion term has genuine purchase intent: high relative CTR, CPC hitting the bid cap (Google wants to bid higher), and micro-conversions (add-to-cart, begin-checkout).
Output: BehavioralSignals computed for each scored term, ready for unified scoring in Plan 05
</objective>

       ```typescript
       export function computeBehavioralIntent(
         term: { ctr: number; avgCpcMicros: number; allConversions: number; conversions: number; costMicros: number; impressions: number },
         tierMedianCtr: number,
         maxCpcCapMicros: number, // from account audit, 0 if unknown
         tierMedianDailySpend: number,
       ): BehavioralSignals
       ```

    2. Signal computations:
       - **rCTR**: `term.ctr / tierMedianCtr` (guard against 0 median — use 0.01 floor)
         - `rCTRScore = min(rCTR / 3.0, 1.0)` — 3x median CTR = max score
       - **CPC ceiling pressure**: `term.avgCpcMicros / maxCpcCapMicros` (if maxCpcCapMicros > 0, else 0)
         - `cpcCeilingScore = min(ratio / 1.0, 1.0)`
       - **Micro-conversion delta**: `term.allConversions - term.conversions` (clamp to 0+)
         - `microConvScore = min(delta / 2.0, 1.0)` — 2+ micro-convs = max score
       - **Cost velocity**: `termDailySpend / tierMedianDailySpend`
         - For terms with any micro-conversions: `min(ratio / 3.0, 1.0) * 0.5`
         - For terms without: `1.0 - min(ratio / 3.0, 1.0)` (fast spend with no signal = bad)

    3. Composite: `0.30 * rCTRScore + 0.25 * cpcCeilingScore + 0.20 * microConvScore + 0.10 * costVelocityScore`

Decision: keep research weights, set cross_device contribution to 0 for now, so composite can be < 1.0 max. This is fine — the unified score adjusts.
