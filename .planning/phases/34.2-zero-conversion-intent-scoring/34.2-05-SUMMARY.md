- Rewrote `determineAction()` with 5-trigger priority matrix (exported for testing): wasted_spend, demote_underperform, promote_conversion, promote_intent, observe
- Unified intent score computed in `scoreTerm()`: 0.55 * feedAlignmentScore + 0.45 * behavioralComposite

- Approval flow uses `targetTier` for correct sequential movement enforcement
- 19 new tests covering all 5 triggers, priority order, sequential movement, and unified scoring

## Decisions Made
- Unified score weights 0.55/0.45 (feed/behavioral) per plan specification
- avgCPA hardcoded at $64.22 from account audit — stable 90-day metric, not worth dynamic querying
- Trigger D requires dual gate (intent >= 0.65 AND supporting evidence) to prevent false positive promotions of zero-conversion terms
- determineAction() exported (was private) so triggers can be unit tested in isolation
- Cloud Run /score-intent uses 10s AbortSignal timeout to prevent blocking the scoring pipeline
- Approval flow prefers targetTier (sequential one-step) over recommendedTier (statistical best-fit) for safe movements
