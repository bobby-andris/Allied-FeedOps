    2. Create `src/feedops/scoring/__init__.py` (empty or with exports)

    3. Create `src/feedops/scoring/attribute_extractor.py`:
       - Class `AttributeExtractor` initialized with product catalog data from Supabase
       - `load_dictionaries()` method: query `product_catalog` table to build:
         - `finishes`: dict of finish names + aliases + 2-3 char codes (PB, ABR, ORB, etc.) from known finishes
         - `collections`: list of 41 collection names (Prestige Regal, Waverly Place, etc.)
         - `product_types`: set of custom_label_0 values (Towel Bar, Soap Dish, etc.)
         - `model_patterns`: regex for model numbers `[A-Za-z]{2,4}[-/]\d+(?:[-/]\d+[A-Za-z]*)*`
         - `dimension_pattern`: regex for dimensions `\d+\s*(?:inch|in|"|'|cm)`
         - `brand_terms`: {"allied brass", "allied"}
       - Use `rapidfuzz.fuzz.token_set_ratio` with threshold >= 85 for fuzzy matching finishes and collections
       - Short finish codes (PB, ORB, ABR) must use word-boundary exact match to avoid false positives
       - `extract(query: str) -> dict`: returns matched attributes with weights:
         - model_number: 1.0 (short-circuit — if found, attribute_score = 1.0)
         - collection: 0.30
         - finish: 0.25
         - dimension: 0.25
         - product_type: 0.15
         - brand: 0.10
       - `score(query: str) -> float`: returns weighted attribute score (0-1), capped at 1.0
       - Handle edge cases: empty queries, single-character queries, all-numeric queries

    4. Create `src/feedops/scoring/tfidf_scorer.py`:
       - Class `TfidfSpecificityScorer` initialized with product catalog data
       - `fit(documents: list[str])` method: fit `TfidfVectorizer` on product titles + descriptions from product_catalog
         - Use `lowercase=True`, `max_features=50000`, `sublinear_tf=True`
       - `score(query: str) -> float`: compute average IDF of query tokens, normalized to 0-1
         - Unknown terms (not in vocabulary) get 80% of max IDF
         - Normalize: `(avg_idf - min_idf) / (max_idf - min_idf)`
       - Memory: ~50MB for TF-IDF model on 80K documents
       - Latency: <1ms per query

    IMPORTANT: Both classes should have a `from_supabase()` classmethod that loads data from the database on initialization. The IntentScorer (Task 2) will call these during Cloud Run startup.
