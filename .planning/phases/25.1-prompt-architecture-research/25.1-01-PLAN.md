  <action>
Create a Python script `scripts/dump_assembled_prompt.py` that:

1. **Loads environment** from `.env.vercel` (Supabase credentials needed for prompt_loader)
2. **Calls `get_system_prompt(mode="batch")`** to get the full system message with all 8 skills
3. **Calls `build_core_prompt()`** for a real SKU (use one from the evaluation set, e.g., "920D-6" or "1042") by loading the ParentSKU from Supabase and building the evidence table
4. **Token counts** both system and user messages using `tiktoken` with `o200k_base` encoding. Install tiktoken if needed: `pip install tiktoken`
5. **Writes** the full system prompt and user prompt to `/tmp/prompt_dump_system.txt` and `/tmp/prompt_dump_user.txt` for manual inspection
6. **Prints** a summary: total chars, total tokens, system vs user breakdown, per-skill char/token counts

Then, using the dumped prompt and the 12 contradictions already identified in 25.1-RESEARCH.md, produce `prompt-audit-report.md` with:

1. **Prompt size analysis**: Exact token counts (not estimates) for system message, user message, and total. Break down by section (SYSTEM_PROMPT base, each skill, each user prompt section).
2. **Contradiction map**: Expand the 12 contradictions from RESEARCH.md with exact quotes and line references from the dumped prompt. Rate each by severity (CRITICAL = directly causes observed bad output, HIGH = likely contributes, MEDIUM = potential issue).
3. **Over-instruction hotspots**: For each topic that appears in 3+ places (competitor materials, finish handling, description length, title rules), list ALL locations with character counts.
4. **GPT-5.2 anti-pattern scorecard**: Score the current prompt against each best practice from the GPT-5.2 prompting guide:
   - CTCO structure compliance (0-10)
   - Over-instruction level (0-10, where 10 = minimal and correct)
   - Contradiction count (0-10, where 10 = zero contradictions)
   - Signal-to-noise ratio (0-10)
   - Verbosity control (0-10)
   - Example placement efficiency (0-10)
5. **Claude-specific content inventory**: List every section in SKILL.md files that is irrelevant to GPT-5.2 (agent metadata, skill identity, when to invoke, rule files, agent guidance) with character counts.
6. **Summary**: The top 5 highest-impact changes ranked by expected quality improvement.
