**Step 1: Select 10 representative SKUs**

Query Supabase to select 10 SKUs optimizing for:
- **Category diversity**: At least 4 different product categories (requirement). Target 6-8 categories for richer signal.
- **Revenue coverage**: Include high-variant-count categories (towel bars, grab bars, shower accessories, mirrors) plus mid-tier.
- **Gold standard signal**: Mix of categories that have gold standard examples (to validate exemplar impact) and categories that don't (to validate generalization). Aim for ~6 gold-standard-adjacent, ~4 non-gold.
- **Multi-SKU product**: Include at least 1 SKU from a multi-SKU family (e.g., DMF-2/2X from the DMF-2 family) to validate hybrid generation benefits.
- **Existing content**: SKUs must have existing `generated_content` rows with `candidate_content` or `approved_content` (so we have "old" descriptions to compare against).

Query pattern:
```sql
SELECT DISTINCT gc.master_sku, gc.candidate_content, gc.approved_content,
       pc.category, pc.product_title
FROM generated_content gc
JOIN product_catalog pc ON LOWER(pc.master_sku) = LOWER(gc.master_sku)
WHERE gc.candidate_content IS NOT NULL OR gc.approved_content IS NOT NULL
ORDER BY pc.category;
```

Select 10 SKUs manually from results, ensuring diversity criteria. Document selection rationale.

**Step 2: Capture old descriptions**

For each SKU, record the current content (prefer approved_content if exists, else candidate_content) as the "old" version. Store in a temporary structure.

**Step 3: Regenerate all 10 SKUs**

Call the Cloud Run `/regenerate` endpoint for each SKU:
```bash
curl -X POST https://feedops-pipeline-623866089882.us-east1.run.app/regenerate \
  -H "Content-Type: application/json" \
  -d '{"master_sku": "SKU-HERE"}'
```

Wait for each to complete (~3 min per SKU, ~30 min total). Record the new candidate_content from the response or query it from Supabase after generation.

**Step 4: Build blind A/B comparison document**

Create `.planning/phases/25-evaluate-iterate/25-01-evaluation-comparisons.md` with this structure:

3. **Differentiation test**: Could you identify this product as Allied Brass (not a generic hardware store) from the winning description? (Yes/No)
4. **Brief note**: What makes the winner better? (1-2 sentences)
