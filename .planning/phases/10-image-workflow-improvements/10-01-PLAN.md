Create a new Next.js API route at `dashboard/src/app/api/images/variant-data/route.ts`.

**Request**: `GET /api/images/variant-data?master_sku=WP-2/16-GAL`

**Response shape**:
```typescript
interface VariantDataResponse {
  variants: VariantDataEntry[]
}

interface VariantDataEntry {
  finish: string
  finish_code: string
  total_impressions: number
  total_clicks: number
  has_lifestyle_image: boolean          // true if any row exists in variant_lifestyle_images
  lifestyle_image_url: string | null    // thumbnail_url or image_url from most recent variant_lifestyle_images row
  lifestyle_image_created_at: string | null
}
```

**Implementation steps**:

1. Parse `master_sku` from `searchParams`. Return 400 if missing.

2. Create Supabase server client using `createClient()` from `@/lib/supabase/server`.

3. Query `search_queries` table for impression data:
   ```sql
   SELECT finish, finish_code, SUM(impressions) as total_impressions, SUM(clicks) as total_clicks
   FROM search_queries
   WHERE master_sku = $master_sku
     AND finish IS NOT NULL
     AND finish_code IS NOT NULL
   GROUP BY finish, finish_code
   ```
   Use Supabase client: `.from('search_queries').select('finish, finish_code, impressions, clicks').eq('master_sku', masterSku).not('finish', 'is', null).not('finish_code', 'is', null)` then aggregate in JS (Supabase client doesn't support GROUP BY directly).

4. Query `variant_lifestyle_images` table for coverage data:
   `.from('variant_lifestyle_images').select('finish_code, thumbnail_url, image_url, created_at').eq('master_sku', masterSku).order('created_at', { ascending: false })`

5. Also query `variant_index` to get the full list of finishes (in case some finishes have no search data):
   `.from('variant_index').select('finish, finish_code').eq('master_sku', masterSku).not('finish', 'is', null).not('finish_code', 'is', null)`

6. Merge data: Start from `variant_index` finishes as the source of truth. For each finish, look up aggregated impressions/clicks from search_queries. Look up lifestyle image existence from variant_lifestyle_images (use first/most recent row per finish_code after ordering by created_at desc).

7. Sort results by `total_impressions` descending (highest impressions first). Finishes with no search data sort to the end.

8. Return `{ variants: VariantDataEntry[] }` with status 200.

**Error handling**: Wrap in try/catch, log errors, return `{ error: string }` with status 500.

**Supabase column check** (from SCHEMA.md):
- `search_queries`: `finish`, `finish_code`, `impressions`, `clicks`, `master_sku`
- `variant_lifestyle_images`: `finish_code`, `thumbnail_url`, `image_url`, `created_at`, `master_sku`
- `variant_index`: `finish`, `finish_code`, `master_sku`

Use `createClient` from `@/lib/supabase/server` (NOT `@/lib/supabase/client`) — this is a server route.
