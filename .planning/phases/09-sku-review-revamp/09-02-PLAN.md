    Replace the placeholder filter bar from Plan 09-01 with a fully wired implementation. Read and write filter state from URL search params using `useSearchParams`, `useRouter`, `usePathname` (already used in sibling components — see SkuReviewClient.tsx for the pattern).

    **URL params used:**
    - `?status=needs-review|partial|approved|published|all` (default: `all`)
    - `?platform=google|bing|shopify|all` (default: `all`)

    **State initialization:**
    ```typescript
    const searchParams = useSearchParams()
    const pathname = usePathname()
    const router = useRouter()

    const activeStatus = searchParams.get('status') ?? 'all'
    const activePlatform = searchParams.get('platform') ?? 'all'
    ```

    **`applyFilter` function** — used by both stats bar and dropdowns:
    ```typescript
    const applyFilter = useCallback((status: string, platform: string) => {
      const params = new URLSearchParams(searchParams.toString())
      if (status === 'all') params.delete('status')
      else params.set('status', status)
      if (platform === 'all') params.delete('platform')
      else params.set('platform', platform)
      router.replace(`${pathname}?${params.toString()}`, { scroll: false })
    }, [searchParams, pathname, router])
    ```

    **Filtered list** — `useMemo` with 4-state support:
    ```typescript
    const filteredSkus = useMemo(() => {
      return skus.filter(sku => {
        const platformsToCheck = activePlatform === 'all'
          ? sku.platform_progress
          : sku.platform_progress.filter(p => p.platform === activePlatform)

        if (activeStatus === 'all') return true

        const targetState = activeStatus === 'needs-review' ? 'blocked'
          : activeStatus === 'partial' ? 'partial'
          : activeStatus === 'approved' ? 'ready'
          : 'published' // activeStatus === 'published'

        return platformsToCheck.some(p => p.state === targetState)
      })
    }, [skus, activeStatus, activePlatform])
    ```

    **Filter bar** — replace the placeholder with a fully wired version including the `partial` status option:
    ```tsx
    <div className="flex gap-3 mb-4">

        <SelectContent>
    ```
