2. Create `src/feedops/providers/claude_provider.py` implementing `ClaudeProvider(LLMProvider)` with the following structure (use the research skeleton from 05-RESEARCH.md as the starting point):

**Constructor** `__init__(self, api_key, model="claude-sonnet-4-6", max_retries=3, *, sdk_timeout_seconds=None, max_total_seconds=None, json_retry_max=None)`:
- Create `AsyncAnthropic(api_key=api_key)` client. If `sdk_timeout_seconds` is provided, pass `timeout=max(sdk_timeout_seconds, 1.0)`.
- Store `model`, `max_retries` (min 1), `max_total_seconds` (default 300.0), `json_retry_max` (default 1).
- Initialize `_last_usage`, `_last_parse_details`, `_last_retry_counts` dicts matching OpenAIProvider's structure exactly.

**`name` property**: Return `f"claude/{self.model}"`.

**`aclose()`**: `await self.client.close()`.

**`health_check()`**: Send a minimal `messages.create()` call with `max_tokens=5`, message "ping", catch exceptions and return False.

**`generate()`** — the core method:
- Check circuit breaker (`circuit_breakers.allow_request(self.name)`), raise `LLMError` if open.
- Start timer with `time.perf_counter()`.
- Build messages: If `image` is provided, create multimodal content blocks using Anthropic's format: `{"type": "image", "source": {"type": "base64", "media_type": image.mime_type, "data": encoded}}`. If no image, simple text message.
- Build `create_kwargs` dict:
  - `model=self.model`
  - `max_tokens=max_completion_tokens or 8000`
  - `messages=messages`
  - `output_config={"format": {"type": "json_schema", "schema": schema}}`
  - `cache_control={"type": "ephemeral"}` (automatic prompt caching)
  - If `system_prompt`: `system=system_prompt`
- Log `reasoning_effort` as a warning if passed (accepted but not used in Phase 5): `logger.debug("reasoning_effort=%s passed to ClaudeProvider but not used in Phase 5", reasoning_effort)`
- Retry loop (mirroring OpenAIProvider pattern):
  - For each attempt up to `max_retries`, check `max_total_seconds` budget.
  - Call `await self.client.messages.create(**create_kwargs)`.
  - Extract usage via `_extract_claude_usage(response)` helper.
  - Extract text: `response.content[0].text` (CRITICAL: NOT `response.choices[0].message.content`).
  - Parse with `_parse_json_payload(content, expected_keys=..., parse_details=...)` imported from `openai_provider.py`.
  - On success: `circuit_breakers.record_success()`, emit `provider_latency_seconds` metric, log `provider.generate.success`, return result.
  - On `json.JSONDecodeError`: increment `json_decode_retries`, log warning with attempt number, check `json_retry_max` budget. If budget exceeded, break. Otherwise backoff and retry. For retry, append repair instruction to messages (non-image path) or rebuild prompt (image path) — same pattern as OpenAIProvider.
  - On other `Exception`: check `is_retryable_provider_error()`, backoff if retryable, break if not. Increment `api_retries`.
- On all retries exhausted: `circuit_breakers.record_failure()`, raise `LLMError`.

**`_extract_claude_usage(response)` module-level helper**:
- Map Anthropic fields: `input_tokens` -> `prompt_tokens`, `output_tokens` -> `completion_tokens`, `cache_read_input_tokens` -> `cached_tokens`.
- Use `getattr(usage, field, 0) or 0` for safety.
- Return standard dict matching OpenAIProvider's `last_usage` shape.

**Properties** (identical to OpenAIProvider): `last_usage`, `last_parse_details`, `last_retry_counts` — all return `.copy()` of internal dicts.

**Key differences from OpenAIProvider to get right:**
- NO `temperature` parameter (Claude uses default; no reasoning_effort/temperature mutual exclusion issue)
- NO `response_format` — use `output_config` instead
- NO `prompt_cache_key` / `prompt_cache_retention` — use `cache_control={"type": "ephemeral"}` instead
- Response path is `response.content[0].text` not `response.choices[0].message.content`
- Image format uses `{"type": "image", "source": {"type": "base64", ...}}` not `{"type": "image_url", "image_url": {...}}`
- System prompt is a separate `system=` kwarg, not a message in the messages list
