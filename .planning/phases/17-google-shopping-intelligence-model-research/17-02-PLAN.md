**Step 1: Select 15 benchmark SKUs from real Allied Brass data**

Use ToolSearch to load `mcp__supabase__execute_sql`, then query for representative SKUs:

```sql
-- Get SKUs across product categories with existing product data
SELECT pc.master_sku, pc.title, pc.description, pc.product_type, pc.material, pc.finish
FROM product_catalog pc
WHERE pc.master_sku IN (
  SELECT DISTINCT master_sku FROM variant_index
)
ORDER BY RANDOM()
LIMIT 50;
```

From the results, manually select 15 SKUs across 3 category clusters per RESEARCH.md:
- 5 grab bars (decorative, different finishes — user-identified PMF category)
- 5 towel/bath accessory SKUs (mid-tier complexity, many finish variants)
- 5 faucet-adjacent/other hardware SKUs (higher attribute complexity)

If category distribution doesn't work cleanly, use whatever product_type clusters emerge from the data. The key is diversity across product complexity levels.

**Step 2: Extract the current production prompt**

Read `src/feedops/pipeline/prompts.py` and `src/feedops/api/prompt_loader.py` to understand the exact prompt template used for content generation. This is the baseline prompt that all 4 models will be tested with.

Also read `src/feedops/api/main.py` to understand how prompts are assembled at generation time (system prompt, evidence, product data structure).

**Step 3: Generate content with all 4 models**

For each of the 15 SKUs, generate title + description using the same prompt baseline with each model:

1. **GPT-4o** (current baseline) — Use the existing OpenAI integration. Call the API directly or use the pipeline's existing generation function. Note: if calling the pipeline API is easier, use `POST /optimize-sku` endpoint on Cloud Run.

2. **GPT-5.2** — Call OpenAI API with model `gpt-5.2` (or `gpt-5.2-0826` if specific version needed). Use the SAME prompt as GPT-4o. If GPT-5.2 is not accessible via the project's API key, document this and skip — the comparison can proceed with 3 models.

3. **Claude Sonnet 4.6** — Call Anthropic API with model `claude-sonnet-4-6`. Use the SAME prompt adapted for Claude's message format (system prompt in system field, user content in user message). The current session has access to Claude — you can generate content directly.

4. **Gemini 2.5 Pro** — Call Google AI API with model `gemini-2.5-pro`. Use the SAME prompt. The `feedops-gemini-api-key` GCP secret exists but you may need to access it via environment variable or GCP Secret Manager. If Gemini API access is blocked, document and skip.

**IMPORTANT**: For models where direct API access is not available in this execution context, use the approach that IS available:
- For Claude: Generate content directly in this session by crafting the prompt and asking Claude to produce the output
- For OpenAI/Gemini: Use `Bash` to call APIs via `curl` with appropriate API keys from environment, OR use the existing Python pipeline code
- If a model is genuinely inaccessible, document why and benchmark with available models

Save all raw outputs to a temporary comparison file for scoring.

**Step 4: Score outputs using LLM-as-judge**

Use the evaluation rubric from RESEARCH.md:
| Criterion | Weight |
|-----------|--------|
| Title formula compliance (Brand + Type + Finish + Key Attribute in first 70 chars) | 20% |
| Keyword coverage (natural language terms, no stuffing) | 20% |
| Description opener quality (first 160 chars front-loads key attributes) | 20% |
| Accuracy (all claims verifiable from product data, nothing invented) | 25% |
| Brand voice consistency (premium positioning, not generic) | 15% |

Score each model's outputs 1-5 per criterion. Use blind labeling (Model A/B/C/D) during scoring to reduce bias. Calculate weighted composite score per SKU and aggregate across all SKUs.

**Step 5: Calculate cost analysis**

Using verified pricing from RESEARCH.md:
- Measure actual input/output token counts from the benchmark runs
- Calculate cost per SKU for each model (standard and batch pricing)
- Extrapolate to full catalog (2,784 master SKUs)
- Include caching scenarios (system prompt reuse)
