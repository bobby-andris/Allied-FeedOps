**Step 1: Prepare search term list**

Use the search terms from RESEARCH.md as a starting point (25-30 terms across 3 tiers). Before scraping, validate search volume using the existing Keyword Planner integration — use `mcp__google-ads-mcp__search` to pull keyword metrics for the candidate terms. Prioritize terms with actual search volume > 100/month. Drop terms with zero volume.

Also query existing `search_queries` table via Supabase MCP to see what terms Allied Brass products currently appear for:
```sql
SELECT search_term, SUM(impressions) as total_impressions, SUM(clicks) as total_clicks
FROM search_queries
GROUP BY search_term
ORDER BY total_impressions DESC
LIMIT 30;
```

Finalize 25-30 search terms combining: user-identified case studies (decorative grab bars), high-volume category terms, and terms where Allied Brass currently has some presence (for comparison).

**Step 2: Execute Apify SERP scraping**

Use ToolSearch to load Apify MCP tools, then use `mcp__Apify__call-actor` to run a Google Shopping scraper. Try `consummate_mandala/google-shopping-scraper` first. Input:
```json
{
  "queries": ["decorative grab bar", "decorative bathroom grab bar", ...],
  "countryCode": "US",
  "maxItems": 30
}
```

If the primary actor fails, try alternatives: `damilo/google-shopping-apify` or `epctex/google-shopping-scraper`.

Wait for the run to complete using `mcp__Apify__get-actor-run` and retrieve results with `mcp__Apify__get-actor-output`.

For each search term, capture:
- All visible listings (top 10-30)
- Per listing: title, price, seller/domain, rating, image URL, GTIN/MPN if shown
- Whether Allied Brass appears (and at what position)

**Step 3: Aggregate competitor data**

From SERP results, build competitor profiles:
- Which domains/sellers appear most frequently across all search terms
- Average position by competitor
- Kingston Brass specifically: how many terms they appear for, average position, title/description patterns
- Allied Brass: how many terms they appear for, average position, where they're absent

Identify top 5 competitors by frequency of appearance.

**Step 4: Full listing comparison for top competitors**

For Allied Brass vs top 3 competitors, compare:
- Title structure and keyword patterns (are competitors using optimized title formulas?)
- Description length and quality (first 160 chars)
- Pricing position (Allied Brass premium vs category average)
- Image quality (resolution, white background, lifestyle images)
- Structured attributes visible in listings
- Review counts and ratings shown

**Step 5: Landing page comparison for top 3 competitors**

Use `agent-browser` (or WebFetch) to examine product pages for top 3 competitor sites:
- Structured data (schema.org/Product markup)
- Product page content quality (description length, specs, reviews)
- Image quality and count
- Domain authority signal (note if selling via Amazon/Home Depot vs direct)

If agent-browser is unavailable or slow, use WebFetch to capture key page elements.

**Step 6: Synthesize competitive gap analysis**

Using the ranking factor framework from Plan 01's output (`docs/research/google-shopping-ranking-factors.md`), analyze:
- Which ranking factors explain the competitive gap (feed quality? bids? domain authority? reviews?)
- For each gap, quantify the evidence (e.g., "Kingston Brass titles average 65 chars with keyword front-loading; Allied Brass titles average 40 chars without keyword optimization")
- Map each gap to a specific optimization action

**Step 7: Produce the optimization checklist**

Per user decision, organize by TWO dimensions:
1. **Controllability**: Feed-controllable | Account-level | External
2. **Priority within each**: Quick Wins (1-2 weeks) | Medium Term (1-4 weeks) | Longer Term (1-3 months)

Use the template from RESEARCH.md Pattern 6 as the structure. Each item must include:
- Specific action
- Expected impact (HIGH/MEDIUM/LOW)
- Evidence source (which data supports this recommendation)
- Scope (all SKUs, specific categories, or case-by-case)

Include bid strategy recommendations alongside feed optimization per user decision (user manages Google Ads directly).

**Step 8: Compile competitive-gap-analysis.md**

Write `docs/research/competitive-gap-analysis.md` with sections:
- Executive Summary (key competitive findings in 5 bullets)
- Methodology (search terms used, scraping approach, data collection dates)
- SERP Landscape (aggregated competitor frequency, Allied Brass visibility rate)
- Competitor Profiles (top 5 competitors with listing patterns and landing page quality)
- Kingston Brass Deep Dive (per user request — primary known competitor)
- Allied Brass Gap Analysis (mapped to ranking factors from Plan 01)
- Case Study: Decorative Grab Bars (user-identified strong PMF category — why page 5?)
- Optimization Checklist (the final deliverable — categorized by controllability + priority)
- Recommended Prompt Changes for Phase 20 (specific title/description/image guidance changes based on competitive evidence)
