Add PMax discovery queries to the script from Task 1. Run these queries to validate Performance Max data availability:

1. **PMax campaign identification:**
```sql
SELECT campaign.id, campaign.name, campaign.advertising_channel_type, campaign.status
FROM campaign
WHERE campaign.advertising_channel_type = 'PERFORMANCE_MAX'
LIMIT 20
```
Document: How many PMax campaigns exist? Active vs paused?

2. **PMax product-level performance:**
```sql
SELECT
  segments.product_item_id,
  segments.date,
  campaign.id,
  campaign.advertising_channel_type,
  metrics.impressions,
  metrics.clicks,
  metrics.conversions,
  metrics.cost_micros
FROM shopping_performance_view
WHERE campaign.advertising_channel_type = 'PERFORMANCE_MAX'
  AND segments.date DURING LAST_30_DAYS
  AND metrics.impressions > 0
ORDER BY metrics.impressions DESC
LIMIT 20
```
Document: Does PMax populate shopping_performance_view with product-level data?

3. **PMax asset group data:**
```sql
SELECT
  asset_group.id,
  asset_group.name,
  asset_group.status,
  asset_group.ad_strength,
  campaign.id
FROM asset_group
WHERE campaign.advertising_channel_type = 'PERFORMANCE_MAX'
LIMIT 20
```
Document: Are asset groups queryable? What data is available?

4. **PMax placement data:**
```sql
SELECT
  performance_max_placement_view.display_name,
  performance_max_placement_view.placement,
  performance_max_placement_view.placement_type,
  metrics.impressions,
  metrics.clicks
FROM performance_max_placement_view
WHERE segments.date DURING LAST_30_DAYS
ORDER BY metrics.impressions DESC
LIMIT 20
```
Document: Where PMax ads appeared (Shopping, Search, YouTube, Display, Gmail, etc.)

```sql
SELECT
  campaign.advertising_channel_type,
  metrics.impressions,
  metrics.clicks,
  metrics.conversions,
  metrics.cost_micros
FROM campaign
WHERE campaign.advertising_channel_type IN ('SHOPPING', 'PERFORMANCE_MAX')
  AND segments.date DURING LAST_30_DAYS
```
Document: Volume comparison between Standard Shopping and PMax.
