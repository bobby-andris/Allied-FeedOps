  <action>
Build a blind A/B comparison document following the established pattern from Phase 25 Plans 01 and 05. For each of the 10 SKUs:

1. **Fetch current production content** (v1) from Supabase `generated_content` table — use the `baseline_content` or `approved_content` field (whichever represents current production). If neither exists, use the old content from the Round 2 comparison document at `.planning/phases/25-evaluate-iterate/25-05-round2-comparisons.md`.

2. **Get v2 content** from the outputs generated in Task 1.

3. **Randomize assignment**: For each SKU, randomly assign v1 and v2 to positions A and B. Use a different random seed than Rounds 1 and 2 to avoid pattern recognition.

4. **Format the comparison document** with this structure per SKU:

```markdown
## SKU: {sku} — {category}

### Titles
| | Title |
|---|---|
| **A** | {randomly assigned title} |
| **B** | {randomly assigned title} |

### Descriptions (Google)
**A:**
{randomly assigned description}

**B:**
{randomly assigned description}

**Your pick — Title:** A / B
**Your pick — Description:** A / B
**Does the winner feel distinctly "Allied Brass"?** Yes / No
```

5. **Append answer key** at the very bottom (clearly separated so it can be hidden during evaluation):

```markdown
---
## ANSWER KEY (DO NOT READ UNTIL EVALUATION COMPLETE)

| SKU | A is | B is |
|-----|------|------|
| 1025U | OLD/NEW | NEW/OLD |
...
```

6. **Include evaluation instructions** at the top:
- Read blind (do not peek at answer key)
- Pick title winner and description winner for each SKU independently
- Answer differentiation question
- Target: 8/10 new content wins for both titles AND descriptions
- Note any specific issues (factual errors, keyword stuffing, missing info)

Focus on Google titles and descriptions for the primary evaluation (these are what shoppers see). Include Bing as a secondary section if it differs materially from Google.
