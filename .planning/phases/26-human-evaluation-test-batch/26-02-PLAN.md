**Step 1: Tally evaluation results**

Using the answer key from Plan 01's blind comparison document and the evaluators' picks from Task 1:

1. Map each evaluator's A/B picks to OLD/NEW
2. Compute per-evaluator win counts (title wins, desc wins, differentiation)
3. Compute consensus: a "new win" requires BOTH evaluators to pick new
4. Create results table:

| # | SKU | Category | Bobby Title | Robert Title | Consensus Title | Bobby Desc | Robert Desc | Consensus Desc | Diff |
|---|-----|----------|:-:|:-:|:-:|:-:|:-:|:-:|:-:|

5. Compare to target: titles >= 8/10, descriptions >= 8/10

**Step 2: Gate decision**

**IF EVAL-03 PASSES (8/10 consensus for both titles AND descriptions):**

Publish the 10 test SKUs as a test batch to Google Sheets:

1. For each of the 10 SKUs, approve the v2 candidate content in Supabase:
   - Update `generated_content` table: set `approved_content` = the v2 candidate content, set `approval_status` = 'approved'
   - OR use the dashboard approve API if available

2. Create a publish batch via the dashboard:
   - POST to `/api/publish/batch` with the 10 SKUs
   - OR use Supabase MCP to insert into `publish_batches` and `batch_sku_assignments`

3. Execute the publish to Google Sheets:
   - The dashboard publish workflow reads `approved_content`, expands variants (28 finishes), writes to Google Sheets
   - Verify rows appear in Google Sheets with correct uppercase `shopify_US_` offer IDs
   - Verify structured_title and structured_description columns are populated

4. Record publish event details (batch_id, timestamp, SKU count) in the results document

**IF EVAL-03 FAILS:**

Document specific failure analysis:
- Which SKUs failed and why (per evaluator feedback)
- Pattern analysis: are failures systematic (prompt issue) or SKU-specific (data issue)?
- Recommendations: fixable iteration vs fundamental rethink
- Do NOT publish — test batch is gated on human approval

**Step 3: Write evaluation results document**

Create `26-02-evaluation-results.md` with:

- EVAL-05 cross-reference: quality scores from Plan 01
- EVAL-06 gate: PASS if test batch published, PENDING if evaluation failed
- Specific evaluator feedback and quotes
- If applicable: test batch publish details (batch_id, Google Sheets row count)
