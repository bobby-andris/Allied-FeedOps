<task type="auto">
  <name>Task 1: Create Pydantic validation models for all collection types</name>
  <files>src/feedops/jobs/validators.py</files>
  <action>
Create `src/feedops/jobs/validators.py` with these Pydantic models:

1. **ValidatedPerformanceMetrics** (VALID-05, VALID-06):
   - `master_sku: str` (min_length=1, max_length=50)
   - `platform: str` (pattern='^(google|bing)$')
   - `avg_impressions: float` (ge=0.0)
   - `avg_clicks: float` (ge=0.0)
   - `avg_ctr: float` (ge=0.0, le=1.0) — VALID-06
   - `avg_conversions: float` (ge=0.0)
   - `avg_conversion_value: float` (ge=0.0)
   - `avg_cvr: float` (ge=0.0, le=1.0)
   - `avg_cost: float` (ge=0.0)
   - `avg_roas: float` (ge=0.0)
   - `baseline_start_date: str` (pattern=YYYY-MM-DD)
   - `baseline_end_date: str` (pattern=YYYY-MM-DD)
   - Field validator: `clicks_lte_impressions` — avg_clicks <= avg_impressions (VALID-06)
   - Field validator: `end_date_after_start` — baseline_end_date > baseline_start_date (VALID-09)

2. **ValidatedSearchTerm** (VALID-05):
   - `query_text: str` (min_length=1)
   - `master_sku: str` (min_length=1)
   - `impressions: int` (ge=0)
   - `clicks: int` (ge=0)
   - Field validator: `clicks_lte_impressions` — clicks <= impressions

3. **ValidatedKeywordMetrics** (VALID-05):
   - `keyword: str` (min_length=1)
   - `avg_monthly_searches: int | None` (ge=0 if present)
   - `competition: str | None` (pattern='^(LOW|MEDIUM|HIGH|UNSPECIFIED)$' if present)
   - `competition_index: int | None` (ge=0, le=100 if present)

4. **ValidatedCustomLabels** (VALID-05):
   - `gmc_offer_id: str` (min_length=1)
   - `custom_labels: dict` with optional string fields for customLabel0-4

Add a module-level constant dict for configurable thresholds:
```python
VALIDATION_THRESHOLDS = {
    "baseline_freshness_days": 60,
    "search_terms_freshness_days": 7,
    "keyword_cache_ttl_days": 30,
    "job_success_threshold": 0.95,
}
```

Use `from pydantic import BaseModel, Field, field_validator` and `ConfigDict(strict=False)` to allow type coercion from API responses.
