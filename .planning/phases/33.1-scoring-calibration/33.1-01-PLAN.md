## Goal

Fix the two core computation bugs in the tier scoring engine:
1. `estimateImpact()` returns $0 for all terms (CVR-based formula produces near-zero deltas)
2. `isMisplaced` flags 95% of terms (no minimum delta, confidence, or impression threshold)

Add a `CalibrationConfig` type and `DEFAULT_CALIBRATION` constant to centralize all threshold values.

## Context

- Tiers were gut-assigned by Robert (business owner), not based on historical data
- The scoring engine correctly identifies where data disagrees with intuition
- But without thresholds, EVERY disagreement is flagged, producing noise instead of signal
- The CVR-based impact formula fails because CVR distributions overlap heavily across tiers
- ROAS-based impact estimation aligns with the scoring engine's 50% ROAS weighting

## must_haves (goal-backward)

- [ ] `CalibrationConfig` interface and `DEFAULT_CALIBRATION` constant in `tier-scoring.types.ts`
- [ ] `estimateImpact()` uses ROAS-based deltas (spend * ROAS_delta) instead of CVR-based deltas
- [ ] `scoreTerm()` gates `isMisplaced` on minFitScoreDelta (0.3), minConfidence (0.40), and minImpressions (50)
- [ ] `TermScore` type includes `fitScoreDelta` field (for UI display and filtering)
- [ ] `TermScore` type includes `dataConfirmed` boolean (where data agrees with gut assignment)
- [ ] `buildHeroCallout()` uses the new calibrated scores (automatically, since it reads isMisplaced)
- [ ] API route passes `DEFAULT_CALIBRATION` through scoring pipeline
- [ ] All existing tests pass, new calibration-specific tests added

<task id="33.1-01-T2" title="Fix estimateImpact to use ROAS-based deltas">
### What
Replace the CVR-based impact formula with ROAS-based estimation. The current formula (`impressions * CVR_delta * AOV`) produces $0 because CVR distributions overlap. The new formula (`spend * ROAS_delta`) produces meaningful values aligned with the 50% ROAS weighting.

### Where
`/Users/bobby/Documents/GitHub/Allied-FeedOps/dashboard/src/lib/optimization/tier-scoring.ts` — `estimateImpact()` function (lines 325-348)

### How
Replace the `estimateImpact` function with:
```typescript
export function estimateImpact(
  term: ExistingFunnelTerm,
  currentDist: TierDistribution,
  targetDist: TierDistribution,
  config: CalibrationConfig = DEFAULT_CALIBRATION
): ImpactRange {
  const monthlySpend = term.total_cost_micros / 1_000_000

  // Use ROAS delta as primary signal (aligned with 50% weighting in scoring)
  const currentRoas = currentDist.metrics.roas.p50
  const targetRoasP25 = targetDist.metrics.roas.p25
  const targetRoasP50 = targetDist.metrics.roas.p50
  const targetRoasP75 = targetDist.metrics.roas.p75

  // Impact = spend * (targetROAS - currentROAS) = incremental revenue
  const lowDelta = targetRoasP25 - currentRoas
  const midDelta = targetRoasP50 - currentRoas
  const highDelta = targetRoasP75 - currentRoas

  // Determine movement direction
  const tierRank: Record<FunnelTier, number> = { HIGH: 3, MEDIUM: 2, LOW: 1 }
  const direction: 'upward' | 'downward' | 'lateral' =
    tierRank[targetDist.tier] > tierRank[currentDist.tier] ? 'upward'
    : tierRank[targetDist.tier] < tierRank[currentDist.tier] ? 'downward'
    : 'lateral'

  return {
    low: Math.max(0, monthlySpend * lowDelta),
    mid: Math.max(0, monthlySpend * midDelta),
    high: Math.max(0, monthlySpend * highDelta),
    currency: 'USD',
    period: 'monthly',
    direction,
  }
}
```

Also update the import at the top of `tier-scoring.ts` to include `CalibrationConfig` and `DEFAULT_CALIBRATION` from the types file.

Remove the `DEFAULT_AOV = 85` constant (now in CalibrationConfig).

### Done when
