## Decisions Made
- ROAS-based impact (spend * ROAS_delta) instead of CVR-based (impressions * CVR_delta * AOV) because CVR distributions overlap heavily across tiers while ROAS aligns with the 50% ROAS weighting in scoring
- DEFAULT_CALIBRATION thresholds (0.3/0.40/50) chosen to filter noise without suppressing genuine opportunities
- direction field added to ImpactRange proactively for Phase 34 wasted spend analysis
- aggregateImpact in API route uses 'lateral' direction as default (aggregate has no single direction)
