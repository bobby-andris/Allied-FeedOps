## Goal

Reframe all UI text from "misplaced" (implies error) to "opportunity" (implies actionable insight). Since tiers were gut-assigned by the business owner, "data suggests different placement" is more accurate and actionable than "wrong tier."

This plan changes ONLY UI text and badge labels. The underlying `isMisplaced` boolean in the data model stays the same (renaming it would be a breaking change across the API and types). The UI simply presents it differently.

## Context

- Plan 33.1-01 already reduced the flagged terms from 95% to ~10-25% through calibration
- The remaining flagged terms are high-confidence, high-impact opportunities worth investigating
- The word "misplaced" implies the business owner made a mistake; "opportunity" frames it as data-driven insight
- `dataConfirmed` field (from 33.1-01) enables showing "Data-confirmed" badges for well-placed terms
