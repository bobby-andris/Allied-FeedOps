**In reason-codes.ts:**

Fix the under_invested detection at the line containing `UNDER_INVESTED_MULTIPLIER`:

Replace:
```typescript
keywordData.avgMonthlySearches > UNDER_INVESTED_MULTIPLIER * (term.totalCostMicros > 0 ? 1 : 0)
```

With:
```typescript
keywordData.avgMonthlySearches > UNDER_INVESTED_MULTIPLIER * (term.totalImpressions ?? 0)
```

This compares search volume against actual impressions, not a boolean. A term with 10K monthly searches but only 100 impressions is genuinely under-invested. The old code treated every term with non-zero cost as having 1 impression equivalent.
