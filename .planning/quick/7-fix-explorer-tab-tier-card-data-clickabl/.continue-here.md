# Continue Here — Explorer Old Logic Bug (COMPREHENSIVE)

## Summary
The Explorer tab and several components still use Phase 33's `isMisplaced` + `recommendedTier` (statistical best-fit) instead of the trigger system (`trigger`, `targetTier`, `classifyAllTerms`). The Action Queue tab is correct — the Explorer tab is wrong.

## Background Context

### Waterfall Shopping Structure (CRITICAL)
- HIGH = top-of-funnel, broad/generic, highest tROAS → LOWEST actual ROAS
- MEDIUM = mid-funnel, category+1 attribute, moderate tROAS
- LOW = bottom-of-funnel, high-intent, lowest tROAS → HIGHEST actual ROAS
- **Promote** = push DOWN funnel (toward LOW) for more aggressive bidding
- **Demote** = push UP funnel (toward HIGH) to restrict bidding
- Queries enter HIGH first; negatives push terms DOWN

### Two Scoring Systems (The Core Problem)
1. **OLD (Phase 33)**: `isMisplaced` boolean + `recommendedTier` = statistical best-fit tier based on ROAS z-scores. Doesn't understand triggers, wasted spend, intent, or the waterfall. Just says "this term's ROAS fits LOW distribution better."
2. **NEW (Phase 33.1+)**: `trigger` + `targetTier` + `recommendedAction` from `determineAction()` in tier-scoring.ts. Understands wasted_spend, demote_underperform, promote_conversion, promote_intent, under_invested. Uses intent scores, behavioral signals, and the waterfall structure.

### What the User Saw
- Action Queue: "unlacquered brass valet rod" → MEDIUM→HIGH (Wasted Spend) ✅ CORRECT
- Explorer → GroupDetail → Optimization Opportunities: 26 terms all HIGH→LOW ❌ WRONG (old logic)

## Implementation Pattern
The correct pattern is already in page.tsx lines 61-69:
```tsx
import { classifyAllTerms } from './lib/reason-codes'

const classifiedTerms = useMemo(() => {
  if (!data) return []
  return classifyAllTerms(data.scores)
}, [data])

const actionableTerms = useMemo(() => {
  return classifiedTerms.filter(t => t.trigger && t.trigger !== 'observe')
}, [classifiedTerms])
```

For GroupDetail/TierDetail/GroupOverview, import `classifyAllTerms` and use it instead of `isMisplaced` filter. Show `targetTier ?? recommendedTier` for the destination tier.
